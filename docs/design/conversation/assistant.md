#### 助手的对话（2026-10-15）

内置运行时、主区开着助手（主对话）时，对话画成和一个人的长期 IM，不再是工作台的任务记录（[主聊天 PRD](../../../.scratch/main-chat/PRD.md) 裁决 60、66）。JC 在 tauri dev 里比完四件各自可切的试验（票 19），四件都取推荐档（裁决 67）：气泡 C、过程一行、时间居中、滚动贴底；定稿是票 20。随后裁决 68（票 21）把看过程的入口从常显的「N 步 ›」改成悬停行里的一个按钮，步数、用时与 token 收进展开区的第一行，上下文百分比不画，卡片与顶栏在跑时说主区那一行的同一句；裁决 69（票 22）把点开后的步骤区换成一张过程卡片：每步一行，最多 8 行，超出在卡片里滚动；2026-10-19 裁决 107、110（票 55、58）把在跑时分到三处（对话里三点气泡，顶栏写做完的那一步的那句话，卡片写「正在输入…」）；2026-10-23 裁决 134、135（票 90、91）收成两处：对话里三点气泡下面加一行「在做什么 · 用时」，卡片只说屏上看不到的，顶栏在跑时留空（见下「在跑时：三点气泡」）；2026-10-30 裁决 159（票 114）把没有回答的一轮收成一行「中途停下 · N 步」，点开是同一张过程卡片（见下「过程（落定后）」的「没有回答的运行」）。工作台的会话、从助手点开的子任务、外置运行时照本文其余各节；2026-10-16 起两边语法统一（你的话在右、时间居中、一步的回复上面什么都不画），密度各按各的，分界见「[User vs Agent 三重区分](./turns.md#user-vs-agent-三重区分单侧容器不是-im-双侧气泡)」。门只有一个，`MainView` 的 `isMainChat`；规则在 `lib/assistant-conversation.ts`（过程卡片的在 `lib/assistant-process.ts`，三点下面那一行的在 `lib/assistant-progress.ts`），部件在 `components/conversation/AssistantParts.tsx`（三点气泡在 `TypingBubble.tsx`，过程卡片在 `AssistantProcessCard.tsx`，卡片本身 2026-10-16 起与工作台共用 `ProcessCard.tsx`）。

**为什么这里是双侧气泡**：工作台的回复是纸上的散文（单侧容器），助手的回复也装进气泡（裁决 66）：「对话是一份文档」正是助手要改掉的（裁决 60：像跟一个真人助理的长期对话），它的回复也短（中位 390 字）。这是密度的差别，不是语法的：你的话在右，2026-10-16 起两边一样（[工作台对话 PRD](../../../.scratch/workbench-conversation/PRD.md) 裁决 2）。「不要边框、不要投影、不要小尾巴」照守，助手也守。

- **滚动时的弹性**（2026-11-06，[PRD](../../../.scratch/main-chat/PRD.md) 裁决 201，票 [150](../../../.scratch/main-chat/issues/150-scroll-spring.md)；推翻裁决 200 第 4 条的「满屏都在动」）：你滚动时，离指针远的行略微落后，停下由弹簧拉回；离指针近的行跟手。iPhone 信息式，压到很轻：静止时与没有它时逐像素相同，一停全部归位。
  - **谁在动**：对话里的每一行作为一个整体：气泡连同它下面的卡片框；回复与它下面展开的过程卡片同进同退；时间条；「中途停下」那一行；三点气泡与下面那一行；它在问你的提问。只动视口里与上下各 160px 里的行。
  - **怎么动**：这一帧内容滚了 Δ，每一行按「离锚点的距离 ÷ 视口半高（封顶 1）」再乘一个增益（`LAG_GAIN`）落后 Δ 的这一部分，再由弹簧拉回原位。增益让落后跟着速度走（裁决 201 第 8 条）：最远的行要滚到约 1,500px/s（`FULL_LAG_SPEED_PX_S`）才顶到 6px，慢慢往下读（约 250px/s）只落后 1px 左右，一甩才看得出拉开再弹回。真窗口实测（2026-11-06）：慢读约 235px/s 最远 1px、停手 200ms 归位；触控板一推带惯性约 485px/s 最远 3px；快滑约 1,765px/s 顶到 6px、停手 400ms 归位；帧间隔中位 17ms，约 580 帧里两帧过 25ms（手势起点 52ms、惯性尾巴 36ms，孤例）。没有增益时每帧整段落后，远处的行从约 35px/s 起就一直顶在 6px：整个滚动过程整屏远处沉 6px，看不出快慢。距离量到行的近边，锚点落在行上就是 0，这一行跟手。锚点：滚轮、触控板、触摸时是指针的纵坐标（指针已离开对话区就用视口中线）；键盘翻页、拖滚动条时是视口中线。新滚进来或新画出来的行从它邻居的位置起，跟着一起落后。
