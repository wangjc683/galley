# v0.5.0 发布

**日期**：2026-09-17（Pre-Flight 起）
**上下文**：v0.4.16 后一天，main 上积了 Goal v2 整条线（09-16 合并）、live
两行窗口、用户消息气泡、写过的文件可点。JC：「我觉得可以发新版本了，看是不是
值得升大版本号了。」裁决 `0.5.0`（minor），不升 `1.0.0`。

## 定级：minor，不是 major

- **minor 的理由**在 09-16 合并 Goal v2 时已裁过：「下一版是 minor 不是
  patch」。按 07-30 规则「minor 要有大到能独立成产品线的单一 feature」——Goal
  从 hive / solo 双引擎换成单线程持久目标，是产品线级重塑，且 Agent API 升
  `schemaVersion: 2`（goal 族 v1 命令退役），契约破坏本身就够 minor。
- **不升 1.0 的理由**：1.0 是对外承诺 API 稳定，而这一版恰恰刚把 goal 族契约
  从 1 破到 2，同一版宣布稳定是矛盾信号；PRD 的「V1.0 Goals」锚在 v0.2 时代，
  从没定过 1.0 门槛，没理由现在把这个号烧掉。等 schemaVersion 2 跑过几个版本、
  社区回验过再谈。
