# 「备忘」页收拾两处：句号不画，单个时间段不画组名

日期：2026-11-11
关联：[主聊天 PRD](../../.scratch/main-chat/PRD.md) 裁决 209；前情 [主对话的上下文与备忘](./2026-10-26-main-chat-memo.md)、裁决 164、166、168、169（11-02 这一页的四轮）

## 起因

JC：「下面我们来优化和打磨备忘，尤其是 UI 上，这部分用户其实就是查看为主，只操作的只有一个删除功能，所以主要在怎么样提升显示美感，优化阅读体验」。

## 现状

读了组件、设计文档与 11-02 的四轮裁决，只读查了库里备忘的形状，截了 JC 停着的真窗口（面板正开在「备忘」页）：6 条，一个组名「本月」，圆点，13px，每条以句号收尾，占面板顶上约 190px。三处杂音：

- **组名大多数日子不带信息**：6 条是 10-26、10-28、11-02 三天记的，此后 9 天没有新写入。「今天」只在那三天出现过，其余日子整页顶着一个「本月」；12 月初起全落进「更早」，此后一直顶着这两个字。时间段是从侧栏借来的，侧栏天天有新对话，备忘不是。
- **每条末尾的句号**：短行排成一列，句号在右边成了一列碎点。
- **页面没说自己是什么**：「你看到的就是它看到的」「要改跟它说」只在空状态里沾了半句。

## 三档

做了一张静态预览（dev 服务器给的 Tailwind 产物与字体，无头 Chrome，面板 320px，浅色；字是虚构的，6 条照 JC 那份的条数与字数，另一份 25 条），现状与三档并排：

| | 做什么 | 6 条内容高 |
|---|---|---|
| 现状 | | 191px |
| 甲，收拾 | 句号不画；只有一个时间段时不画组名；末尾一句 12px 灰字说明 | 224px，不算那句说明 168px |
| 乙，一页纸 | 甲，再把整份包进一个框，题头「关于你 · 6 条」 | 268px |
| 丙，阅读档 | 乙，再加 14px / 22px、横格线代替圆点、日子常驻右边 | 323px |

主会话推荐甲：这一页 JC 两次往紧里收（裁决 164、168），甲是唯一不变松的一档。乙的 6 条版更像个成品，但面板本身已经是容器，待办页直接铺在画布上，切页签一边有框一边没框，25 条时是一张很长的卡片。丙右边一列常驻的日子读成流水账，正文被挤得多折行。

主会话同轮点明两处：句号这件 11-02 提过一次、JC 没选（裁决 164 第 3 条），这次有图；「只有一个时间段时不画组名」是带条件的规则，不带条件的写法是组名一直画。

JC：「甲，按你推荐开始执行，脚注不要」。

## 落地

- `gui/src/lib/memo.ts` 加 `memoShownText`：末尾的一个「。」或「.」不画。只改画法，库里、CLI、段首照旧；手册不改。画三处：「备忘」页的行、回复下的备忘卡片（`memoCardParts`）、删除后的提示条（`memoToastText`）。
- `MemoPage.tsx`：只有一个时间段时不画 `GroupLabel`。
- 脚注没做。

## 没选

- 乙、丙：见上。
- 让模型不写句号（改手册）：要靠它照做，已有的几条也还带着；画的时候去掉是确定的。
- 脚注：JC 不要。
