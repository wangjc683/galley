# v0.4.16 发布

**日期**：2026-09-16
**上下文**：v0.4.15 后两天，一天内落了五个 GUI 提交：两条社区反馈（中文
Settings 侧栏、Windows 图标发虚）、一次参考组件对表引发的过程区重排、模型
combobox、置顶提位。JC 裁「按 0.4.16 开始发版」，理由：两条社区反馈已落地
应尽快回到用户手里；Windows 字重变体那条 deferred 的启动信号本身就是
「图标修复发版后社区仍反馈」，不发信号永远不来；批次里剩下的项走下一个 patch。

## 范围（git log v0.4.15..，5 个功能提交）

1. **模型列表并进模型字段做 combobox**（`a8b4f7e9`）——自动拉取路径走
   probe 状态，列表不再凭空出现。见
   [模型列表改为模型输入框的候选项](./2026-09-16-model-list-combobox.md)。

   辅助标签看不清。见
   [Settings 侧栏中文改为主标签](./2026-09-16-settings-sidebar-chinese-primary.md)。
3. **低 DPR 屏 Phosphor 图标加粗 + 字体栈加雅黑**（`37f71134`）——社区
   Windows 截图发虚。见
   [Windows 图标 / 文字发虚](./2026-09-16-windows-low-dpr-icons-and-font-stack.md)。
4. **步序改为序号栏 + 过程区 StepRegion**（`8194e730`）——同日五轮真机裁决
   的重排，`Conversation.tsx` 与 `ToolCallout.tsx` 改动最大，抽出
   `ExpandSection` / `StepRegion`。见
   [步号改序号栏](./2026-09-16-step-marker-recede-and-reference-audit.md)。

`runner/`、`managed-ga/` 均未动。

## Smoke 计划（draft 门）

序号栏那次重写动了过程区两百多行且五轮裁决都盯静态截图，发前要跑动态场景：

- macOS：多步 live run（看 in-flight 行空 gutter → 落定出序号、rail 连续）、
  ask_user 交互、审批卡、`/restore` 旧会话的 settled 折叠区；模型 Settings
  新建 provider 填 Key 看「读取中 → 找到 N 个模型」与 caret 下拉；⋯ 菜单
  首项是置顶。
- Windows 真机 100% / 125%：侧栏与 topbar 图标线宽（thin 图标应与「新对话」
  bold 加号的实感接近）、中文 Settings 侧栏主标签可读性。图标修复只在
  ≤1.5dppx 生效，Mac Retina 验不到。
- app-update hop `v0.4.15 → v0.4.16` 发布后走 step 10。
