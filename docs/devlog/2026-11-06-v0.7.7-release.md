- **patch（v0.7.7）。** 代码只改 `gui/src`（`git diff --name-only v0.7.6..HEAD` 在 `managed-ga`、`runner`、`core`、`cli`、`scripts`、`.github` 等目录下为空），只影响内置运行时的主对话；工作台、子任务、外置运行时零变化。没有迁移、没有 Agent API 改动。裁决 199 推翻的是「气泡下面留 30px 给按钮」的画法，不是拿掉一个系统，不触发「拿掉也定级」。
- **GA baseline 仍是 `d66509b`，上游的不跟。** 上游 `main` 现在是 `68d996a`，比 `d66509b` 多 8 个提交（GitHub compare API 查于 2026-11-06）：v0.7.6 判过的 4 个（反射模式、`frontends/p2p_ws_client.py`），加上 `frontends/hub.py` / `hub_p2p.py` 的 FastAPI lifespan 修复（Galley 不加载 hub 前端），与 Claude 的 `show_thinking`（`mykey` 里的可选键，默认关时请求不变；`runner/`、`core/src`、`managed-ga/patches` 里 grep `show_thinking` 为空，Galley 不设）。没有一处改变内置运行时的行为，下次发版照例再看。

- **W1**：交草稿时问 JC。主会话推荐这次做：滚动弹簧靠 `wheel` 事件分辨人滚与程序滚，惯性与平滑滚动只在 WKWebView 里量过；票 150 的 Open risks 写了 Windows（WebView2）1.25 / 1.5 像素比下的台阶感与清晰度只能真机看、Chromium 的滚动锚定可能被当成人滚。W1 从 v0.7.1 欠到现在，迁移 053–056 也还没在 Windows 的旧库上跑过。
