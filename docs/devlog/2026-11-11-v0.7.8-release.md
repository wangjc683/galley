## 裁决

- **现在发，不再攒。** 内容够（前三个补丁版是 22、86、98 个提交），而这一版带着几样只有发版才能验的东西：打包映射与 `release.yml` 的改动（审计票 04、07）、shell 插件移除、`--sop-path` 移除、NSIS 钩子。再叠新内容，草稿红了更难定位。没选的两项：先跑 `release.yml` 的 dry-run 再打 tag（会改掉 JC 11-10 的裁决，单列给他，他选了不带 dry-run 的那一项）；再攒一轮。

- **GA baseline 仍是 `d66509b`，上游的不跟。** 上游 `main` 还是 `68d996a`（`git ls-remote` 查于 2026-11-11），与 v0.7.7 判过的是同一个提交，那 8 个提交的判断见 [v0.7.7 devlog](./2026-11-06-v0.7.7-release.md)。

## 冒烟清单

dev 里已验过的见两篇 devlog 的「没做完的」与 project status；安装包上要看的是只有打包版能看的那几样。装草稿前要停掉 dev（两边共用数据目录）。

主会话在草稿上做的只读核对（不用装）：三个平台的资产与 `latest.json`；Intel DMG 只读挂载，看 `Resources/runner/` 下只有 `.py`、没有 `tests/`，`Resources/managed-ga/code/assets/` 下没有 `demo/` 与技术报告 PDF，内置 CLI 报 0.7.8、`schemaVersion 3`；安装包比 v0.7.7 小多少（notes 写的「约 22 MB」对着实际数字改）。

- **S1（Mac 草稿，必过）**：启动后没有权限报错的弹窗或空白窗口（shell 插件移除）；设置里各 IM 渠道是连上的（`--sop-path` 移除）；主对话发一句要查网页的话，答得出来（`runner/*.py` 的打包映射、瘦过的载荷）。
- **S2（Mac 草稿）**：在主对话说一句带周期的事，提醒时刻定在几分钟后，比如「每天这个点提醒我喝水，记成重复的待办」。看三样：到点系统通知响（dev 版不发系统通知，「响」只有安装包能看）；勾掉它，这一行淡出合拢、下一期出现；再建一件留着不勾过夜，第二天同一时刻看它再响一次（没了结的这一期重挂，只有自动测试），看完「不再重复」并删除。过夜那一步等不了就记欠账。
- **W1（Windows 草稿，主会话推荐这次做）**：装 NSIS 安装包，走 [Windows 清单](../windows-build-checklist.md)，重点是「Manual upgrade」那一条：旧版开着、安装目录下的 `galley` CLI 也在跑时装新版，安装前的钩子把两个都关掉、不出文件占用的对话框（只有 Windows 能验）。旧库会跑迁移 053–057，启动前 Core 照旧自动备份。W1 从 v0.7.1 欠到现在。
