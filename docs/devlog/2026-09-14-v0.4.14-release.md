# v0.4.14 发布

**日期**：2026-09-14

## 范围（git log v0.4.13..，3 个提交）

   全局 `user-select: none` 而 AskUserBubble 漏开 `select-text`；改走
   MarkdownView，加 remark-breaks `softBreaks` 保住单换行；Composer 占位按
   候选数分支。见 [可选中](./2026-09-14-ask-user-selectable-markdown.md)。

   不发送；`candidateLayout` 按内容切 chip / 竖排，列宽取最长一条；回显列
   候选并勾所选。见 [候选三改](./2026-09-14-ask-user-chips-fill-list-echo.md)。
3. **拆分调用合并**（`964b0df6`）——grok-4.6 把一个问题拆成五个单候选
   ask_user；runner / GUI 读取侧同问题合并。见
   [拆分合并](./2026-09-14-ask-user-split-calls-merge.md)。

（`_extract_ask_user`）；`managed-ga/` 零提交。gui 新增依赖 remark-breaks。
