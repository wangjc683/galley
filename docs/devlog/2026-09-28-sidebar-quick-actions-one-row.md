# 侧栏顶部快捷入口：四行压成一行

Date: 2026-09-28
Status: implemented; two live-test rounds on JC's desktop the same day (five
layouts, then three forms of 新对话); switcher removed; static gates green;
unreleased
Related: [layout-and-chrome §4.2 Sidebar](../design/layout-and-chrome.md),
[08-13 侧栏导航参考审计](./2026-08-13-sidebar-nav-reference-audit.md),
[英文文案稿](../archive/english-copy-draft.md)

## 起因

JC：侧栏顶部这块，除了新对话还算比较高频，搜索 / 定时 / 项目很多时候没那么高频，现在
的布局下空间比较浪费。

## 现状与约束

- 四行各约 36px，加上下边距共约 152px；会话行最少 48px，这块约占三条会话的位置。
- 设计文档原写「New Chat / Search / Project Review 是最高频入口」，前提被 JC 的用法推翻。
- 本机数据（workbench.db 只读）：项目 0 个、定时任务 0 个；搜索没有打点。社区用法未知，
  所以降级、不藏。
- 必须保住：定时徽标（只在有待处理事项时出现，08-13）；项目按钮的按下态（开启后时间线
  整体换成 Project Review）。
- 不能碰：常驻搜索框（命令面板是既定裁决）；悬停瞬时、不做滑动高亮（08-13）。

## 第一轮：五种布局

现状 / A 一行（新对话带字，其余三个图标）/ A2 一行·搜索带字 / B 两行 / E 底栏。A2 是讨论中
追加的：JC 说平时搜索主要点侧栏那一行、不按 ⌘K，搜索是第二常用入口。我推荐 A。
JC 真机：**一行最舒服**。

## 第二轮：新对话要不要也去字

JC 提出新对话的文字也降为提示、做成一行四个按钮，新对话在视觉层级上最优先。讨论：

- 去字不省高度（已经是一行），换来的是各宽度、各语言一致；丢的是文字这个最强的主次信号，
  以及「新对话 · 项目名」（主区空状态「在 X 里交代什么？」兜底）。
- 主次只能靠颜色 / 粗细 / 位置 / 外框补。排除杏沙填充（发送按钮是全局唯一杏沙 CTA，
  `conversation.md`）和杏色浅底（按下 / 选中的语言，和项目按钮开启态撞）。
- 候选 I1 纯图标、I2 加号套中性细描边框。我倾向默认保留文字，若去字选 I2。

JC 真机：**一行带文字**。

## 英文：New chat

- 实测 Inter 500 13px：「New conversation」112.8px、「New chat」58.8px、「New」28.2px、
  「新对话」39px。原实现是先截断再隐藏，英文会显示成「New conv…」。
- 我先推荐「New」（中英共用一个门槛），因为英文稿写着「不引入 chat，conversation 是 Galley
  的词」。JC 倾向 New chat。
- 定案：**创建对话的动作在英文里统一叫 New chat**（句首大写，与英文界面一致）；名词仍是
  conversation。改了侧栏、侧栏项目版、主区未开会话时的标题、命令面板、快捷键说明、项目行
  「＋」的提示（New chat in X）、空项目里的按钮（New chat）。IM 命令说明
  「/new Start a new conversation」属 IM 侧，不动。英文稿规则改写为「只有创建动作用 chat」。
- 更正一处：我在讨论里把顶栏那条算作「动作」，实际上它是主区没有打开会话时的标题；读作
  「New chat」同样自然，一起改了。
- 会话默认标题「新对话」是 Core 里写死的中文（`DEFAULT_NEW_SESSION_TITLE`），不在这次范围。

## 不截断规则

新对话的动作文字要么完整显示，要么只剩加号，不截成半截。门槛按语言：中文 198px、英文
220px（算式写在 `NewChatButton` 注释里）。项目版只截项目名，动作文字始终完整。悬停提示
始终给完整标签 + ⌘N。

## 落地

- `SidebarQuickActions`：一行；三个图标按钮 32px，悬停提示写名称与快捷键；定时角标在时钟
  右上角（弹跳与挂载抑制保留）；项目按钮按下态沿用原有语言。
- 新建项目的 `+` 移到 Project Review 第一个分组标题右侧（有活跃项目时是「活跃项目」，
  只有更早项目时是那个分组），24px 按钮不撑高标题行。
- 删掉不再使用的「进入项目视图 / Show projects」词条（项目按钮提示改为「项目」）。
- 执行：两张 Opus 票（五档切换器；删落选档 + New chat + 不截断 + I1 / I2），拆切换器与
  文档由主会话做。

## 已知边角

- 项目上下文、宽度刚过门槛时（中文约 198–215px），「 · 项目名」可能只剩一个省略号。
- 侧栏最窄 134px 时，三个图标挤到约 29px 宽。
- 窗口 960px、侧栏默认 20% 时约 192px，新对话默认就只剩加号。

纯前端，内置 / 外置两种运行时模式零差异。
