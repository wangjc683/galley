# v0.4.3 发布：会话智能（自动标题 + ghost 建议）与阅读体验（run 折叠 + 高亮笔）

**日期**：2026-08-06
**范围**：v0.4.3 发布叙事，聚合 `v0.4.2..HEAD`（约 26 个提交）

## 背景

`v0.4.2`（2026-08-03）之后三天里累积了四条线：两个辅助 LLM 功能
（会话自动标题、composer 下一步 ghost 建议）、MainView 阅读体验重构
（run 折叠、用户消息高亮笔化）、六轮 UI polish marathon，以及内置 GA
补丁 `0017`（Anthropic 兼容端点 input token 记账）。各线均有独立
provenance，本条只记**为什么打包成 `v0.4.3`**、发布准备中修掉的两个
gate 缺口，以及发布点的聚合状态。

## 版本决策：patch

沿用 `v0.4.1` 确立、`v0.4.2` 复认的定级规则（按单个功能量级判，minor
要求够一条独立产品线）。JC 裁决（2026-08-06）：

- 自动标题 / ghost 建议、run 折叠都是既有会话面上的增强，单个都不够
  minor 量级；
- 规则按单功能量级判、不按批次总量判——否则每次攒多了都有理由升 minor。

产品形态、Agent API schema（`schemaVersion: 1`）、GA baseline
（`d8d90ee` 不变）、更新渠道策略均不变。

## 发布准备修掉的两个 gate 缺口

**CI 自 2026-08-04 起在 main 上连红**，发布 pre-flight 才暴露——两个
缺口都在发布准备中修复（`35385273`、`b4254df4`）：

1. **IPC drift gate**：auto-title 给 python / rust 面加了
   `generate_title` 命令，但 `gui/src/types/ipc.ts` 没有镜像——GUI 确实
   永远不发这个命令（它是 Core watcher → bridge 的），但该文件是全量
   wire protocol 的 ts 面。补上镜像接口（`finalAnswer?` 沿 AttachPet
   的 optional 约定）。
2. **GA baseline drift gate**：`0017` 是第一个「补丁单独落地、不随
   baseline 升级」的案例。它如实把 `patches/manifest.md` 的
   "Last replay verified" 更到 2026-08-06，但 gate 要求该日期与
   `manifest.json` 的 `auditedAt`（2026-08-03，上游审计日，未变是对的）
   **相等**——这个不变量建立在「replay 只发生在升级时」的旧假设上。
   两个日期都是真实的，改任何一边都是造假，所以修 gate：允许 replay
   日期**不早于** auditedAt（保留抓「升级忘更新」的原意）。

CI 连红三天没被注意，说明红灯疲劳已经发生；这次的直接教训是
feature 落地时就该看一眼 push 后的 check.yml 结论。
