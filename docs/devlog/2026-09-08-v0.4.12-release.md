# v0.4.12 发布

**日期**：2026-09-08
**上下文**：v0.4.11（2026-08-31）后主干攒了一周：两个社区 issue、一个社区
PR、两个另一 agent 做的阅读面板功能，加上同日一连串打磨。JC 起手叫它
hotfix，按 SOP"新功能 + 修复不叫 hotfix"，notes 和定级按实际内容写。

## 范围（git log v0.4.11..，13 个提交）

按用户可见的变化收拢，不按提交数：

1. **托管微信渠道不回消息（PR #25 诊断）**——v0.4.9 起上游 `wechatapp`
   默认把消息转给一个没装模型加载器的 conductor 子进程。修在 supervisor
   侧：固定进程内 agent、屏蔽 `/switch`。见
   [conductor 死路](./2026-09-08-wechat-conductor-mode-dead-path.md)。
2. **模型配置 UX（issue #26）**——推理强度提为编辑器一级字段（新增服务商
   时也能设）、「我的模型」拖拽排序、推理强度 chip 改大写等宽、圆点 tooltip
   写明"移到顶部"。见 [issue #26](./2026-09-08-issue-26-model-config-ux.md)。
3. **搜索定位到消息（issue #27）**——命令面板的对话内容命中现在打开会话并
   停到命中那一行，词级高亮，候选行也高亮；「最近会话」改子串匹配、候选池
   扩到全部会话。见 [issue #27](./2026-09-08-issue-27-message-search-locate.md)。
4. **透明度 token 修复**——`--opacity-*` 是无单位小数，`color-mix` 整条
   丢弃，全仓 77 处填充自 token 建立起从未渲染。改成百分比后按钮、工具
   callout、徽章等第一次长出设计意图的底色。JC 真机过了一遍。
5. **本地文件引用与 Markdown 预览**、**Git 工作区改动审阅**——另一 agent
   完成的两块阅读面板功能（[预览](./2026-09-08-local-file-preview.md)、
   [Git 审阅](./2026-09-08-git-worktree-review.md)），发版前经一轮 UX 复审
   （[打磨](./2026-09-08-reading-panel-polish.md)）：共享 header、Galley
   自己的文件列表、状态统一、分栏阈值 880、顶部图标改 `GitDiff`。

Core 变化全是 additive（`local_file.access`、`git.review`），schemaVersion
不动。runner 只动 IM supervisor；managed-ga 零提交。

## 定级

`v0.4.12`，patch。按 `v0.4.1` 规则只看最大单项：阅读面板（Markdown 预览
+ Git 审阅）是对话主区旁的结果审阅面，量级是"主区的扩展"而不是定时任务
那种带独立 sidebar 面的产品线；其余都是既有面上的增量。**Rejected**：
`0.5.0`——阅读面板确实是新交互面，但没有自己的导航入口和数据面，按功能
量级归 0.4 线。JC 若在 draft 门认为该升 minor，删 tag 重打即可。
