# v0.6.0 发布

**日期**：2026-10-05
**上下文**：v0.5.6 后四天，main 上是三条线：10-03 / 10-04 的界面打磨、10-04 浏览器控制一轮、10-05 去掉审批系统。
JC：「准备发版，讨论下版本号」→「定 v0.6.0」。

## 裁决

- **发，minor（v0.6.0）。** 按现行规则（`v0.4.1` 起，看最大单个功能、不看批量）字面判是 patch：浏览器控制这一轮是既有能力上的增强，
  与 `v0.4.7`（Discord 并行监督，JC 推翻 minor 先例裁 patch）同级；去掉审批不增加能力。定 minor 的理由是规则没覆盖的一类：
  - **规则管的是「加了什么」**。07-30、08-06 两次裁决是防「攒批升 minor」，没讨论过拿掉一整套面向用户的系统。唯一可比的先例是
    `v0.5.0`，它退役了 hive / solo 引擎，定的是 minor；此前没有 patch 拿掉过一整个用户可见的系统。
  - **社区有人在用审批**。「零使用」只是 JC 本机 `workbench.db`（136 个会话）。GitHub #16（lumiai101）描述过「Agent 停在审批/确认
    环节等我点同意」，并要「等待审批」单独一种提示音。stable 渠道自动推更新，这类用户若拿到 patch，会在不知情时失去安全闸门：
    `code_run` 从此不等确认直接执行。版本号是最便宜的告知。
  - minor 的成本近乎零：SOP 里 minor 与 patch 同走 stable、同一流程，`v0.5.0` 也是当场 promote。
  - **落选**：v0.5.7（严格按现行规则、不补条款）——#16 这类用户只能从 notes 得知审批没了。`1.0` 不在讨论范围。
- **规则补一条**（JC 选 A 时一并定）：拿掉一整套面向用户、改变产品行为或安全模型的系统，即使没有新增功能也判 minor。写进
  [project status](../project-status.md)「Release Version Rules」。
- **Agent API 不升版本**：仍是 `schemaVersion: 2`。`approvalMode` 可选、从未输出，去掉不算破坏；`waiting_approval` 保留、不再产生
  （[稳定性 §7.1](../agent-api/stability-and-versioning.md)）。
- **打包门禁必须跑**：`managed-ga/`（补丁 `0028`、`TMWebDriver.py`、manifest）与 `runner/`（常驻浏览器桥、审批移除）都动了。
  本机 `mac-x64` 通过。
- **GA baseline 本次不审计（连续第六次）。** 上游 `main` 仍是 `f308ee7`（`gh api` 查于 2026-10-05，提交于 09-30），与 v0.5.5 / v0.5.6
  核对时同一提交，引擎改动没有变化，结论沿用 [v0.5.6 devlog](./2026-10-01-v0.5.6-release.md)：记忆提炼提示词允许模型改写已有记忆条目，
  属于用户状态，应单独一次审计、引入后观察，不夹在发版里。v0.5.6 建议基线审计单独起一次，起不起、何时起仍待 JC 定。
- **更新渠道**：stable，publish + 冒烟后推 stable。

## Pre-flight（本机实测）

- 打包门禁 `mac-x64` 通过（`bundle-python.sh mac-x64` + `check-bundled-python-managed-ga.sh`，managed GA import OK，bundle 162M）。
- 本地：check.yml 六个门禁脚本全绿；gui typecheck / lint / 629 tests；runner ruff / mypy strict / 496 passed；`cargo check` 与
  `cargo test --workspace`（564 passed）；`check-version-consistency --tag=v0.6.0` 通过，`Cargo.lock` 与 manifest 一致。
- 插曲：cargo 第一次与打包门禁并行，tauri build.rs 撞上正在重写的 `core/python-bundle`（资源路径不存在），打包跑完后重跑即绿。
  门禁并行时 cargo 要排在打包之后。

  不残留）、18765 被其他程序占用时的提示；未验证状态下走一遍新用户流程（「浏览器控制 · 待解锁」→ 安装扩展 → 自动验证 →「试一试」）。
