## 为什么当时的论证错了

稀缺性论证把「同一句反复出现导致失力」的风险，套在了一个**本来就不是
同一句话**的设计上：三条件绑定（silent → Tractatus 7 / quiet → PI §19 /
working → PI §43）让每次出现都在回应工作区的真实状态，加上每次驻留
冻结，反墙纸机制早已内建。用错的类比是「书只有一页题词」；更准的是
**章节题词**——每个门槛都被框一次，是正当的文学形式。

方法论教训（恰好是当年 deferred 的 §66 候选题词本身）：**Denk nicht,
sondern schau——别想，去看。**气质判断以 dogfood 为准，理论让位于体验。
