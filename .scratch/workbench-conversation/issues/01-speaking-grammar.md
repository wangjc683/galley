# 01 工作台里你的话在右、时间居中，一步就答完的回复不画折叠头

Status: open

来源：[工作台对话 PRD](../PRD.md) 裁决 2、3、7（2026-10-16，JC：「按建议推进」）。只改 GUI 与文档，不碰 Rust。
与票 [02](./02-process-one-line-per-step.md)（折叠头后面的步骤）并行，两张都会动 `Conversation.tsx` 与 `conversation.md`，本票先合。

## 目标

工作台的会话（普通会话、从助手点开的子任务、外置运行时的会话）里，你的话在右、时间在两条消息中间居中；一步就答完的回复上面不再有「1 步 · 用时…」。助手的对话一处不变（逐像素）。

## 一、你的话在右

- `MessageUser` 今天用 `align="end"` 给助手靠右。工作台也靠右：宽度随内容，上限同助手 `min(80%, 560px)`；来源图标行（Supervisor、「来自主对话」）与长消息的「展开 / 收起」跟着靠右（助手里已经这样，复用）。
- 两边都靠右后，`align` 可能只剩一种取值：能删就删，不留死参数。助手与工作台仍不同的只有：悬停复制（助手没有、工作台有，裁决 73 第 4 条）与行间距（助手的 `assistantRowGap`）。
- ask_user 的回答是普通的用户消息，跟着靠右。提问块（`AskUserBubble` / `AnsweredAskUser`）留在左边，样子不变。
- 以气泡为锚的东西照旧对得上，逐个确认：提交后贴顶滚动（`conversation.md`「Scroll behaviour」）、⌥↑ / ⌥↓、`data-role="user-msg"`、问题轨的锚与 tooltip、⌘F 查找结果的高亮。

## 二、悬停复制挪到气泡下方

- 今天在气泡右下角外侧（`MessageUser.tsx` 里 `left-full` 那个绝对定位）。改为气泡下方、右缘对齐气泡右缘，与回复行动条同一种 `ActionChip`（inline 皮），离气泡 6px（同回复：气泡下 6px、chip 24px）。悬停气泡这一组时出现，隐藏时照旧占位（`opacity` + `pointer-events-none`，不卸载），「已复制」1.5s 内保持可见。
- **间距**：这一行（6 + 24 = 30px）就当你 → 下一样东西（折叠头、live 行、回复、提问块）的间距，不再另加 `my-5` 的下半；上面（回复 → 你）照旧。思路同助手「它 → 你 30px 由行动条占着」（`assistantRowGap` 的注释）。改前改后的竖向距离量出来写进 Comments。
- 长消息折叠时「展开 / 收起」也在气泡下方：两样怎么排（同一行两端、上下两行……）你定，原则是不互相盖、悬停不跳；写进 Comments、附截图。
- 「复制」复制的仍是原文全文（折叠的长消息也是全文），这是工作台保留它的理由。

## 三、时间居中

- 工作台的断点时间从气泡上方左对齐，改成两条消息之间居中的一行，用助手同一个 `AssistantTimeDivider`（`AssistantParts.tsx`）。它两边共用后，名字里的 Assistant 不再准确：改名、挪地方你定，别复制一份。
- 上下间距照助手；紧接在回复下面时上面不再加（回复的行动条已经占位）——工作台回复的行动条同样隐藏占位，量一下这条在工作台是否同样成立，写进 Comments。
- 断点规则不变（`userTimeMarks`）：工作台没有问候、没有叫醒行，照旧只跟你的消息比；Supervisor 来源的消息照旧总有时间。来源图标留在气泡上方（靠右），与时间分开。分页时的页前比较（`previousUserCreatedAt`）照旧。

## 四、问题轨不贴气泡

- 栏宽撑满主区时（小窗口；宽松档在不够宽的窗口），气泡右缘正好落在轨的点的左缘：栏是 `px-8`（`MainView.tsx:448`），轨是 `right-3 w-5`（`UserQuestionRail.tsx:422`），点占离主区右缘 12–32px，气泡右缘在 32px。
- 做法你定（轨内缩、有轨时气泡让出几像素……），要求：任何窗口宽度、两档阅读宽度下，点与气泡右缘至少 8px；回复散文不受影响；没有轨的画面（助手）不变；Windows 常驻滚动条的情况想一遍。写进 Comments。

## 五、一步就答完的回复不画折叠头

- 今天落定的运行一律折叠、`foldable` 不看步数（`gui/src/lib/run-groups.ts`），一步就答完的回复上面也有「1 步 · 用时…」。改为：完成的运行只有一步（`stats.stepCount === 1`）时，不画折叠头、不画步骤标记、不画 StrongHr，只有回复；token 与上下文照旧在回复的悬停行里（`runTelemetry ?? turn.telemetry`）。
- 判据只看步数，一句话的规则，有没有推理都不画（库里 46 个一步回复里 0 个带推理或开场白；同助手的「一步就答完的什么都不留」）。若一步的完成运行里还能带工具（照理收口那一步是 `no_tool`），查清楚写进 Comments，有就照样不画、报给主会话。
- 在跑到落定的那一下（live 窗口收合的 sweep，`Conversation.tsx` 的 settling 一段）：一步的运行收合后什么都不剩，回复不能跳。
- 不受影响：两步以上照旧；没有回答的运行（中止、出错、停在步数上限）照旧整段平铺；`/btw` 照旧；助手对话本来就不画。
- 这实现了 deferred「单步 run 的『第 1 步』前缀收敛」里的「删整行」（那一节由主会话撤下）：它留下的两条约束，DetailPanel 入口是上面接受的代价；StrongHr 需要上方有行动列，没有就不画。

## 六、文档

- `docs/design/conversation.md`，逐处照实改：
  - 「User vs Agent 三重区分」：表里「对齐」一行；「不要 right-align」一段推翻，理由引工作台对话 PRD 裁决 2；`:38` 那段「只管工作台」改成新的分界：语法统一（你在右、时间居中、一步怎么写），密度按关系与工作分（裁决 1）。「不要边框、不要投影、不要小尾巴」照守。
  - 「杏沙气泡」：贴栏左缘、文字缩进、`left-full` chip 的说法；「助手的对话」里「工作台里你的消息照旧有悬停复制，有意不统一」那句的理由改说为密度差异。
  - 「发送时间」的位置；「Message Actions」里 user hover chip 的位置与「间距注意」；「Scroll behaviour」（锚还在）；「Right Question Rail」（内缩）；「Turn 结构」（一步的运行）。
- 其他设计文档里「用户消息左对齐」一类的说法 grep 一遍，中英两种写法都搜（right-align、左对齐、右对齐、靠右、align）。
- 不写 devlog、不改 PRD 与 deferred、不改各票的 Status 行（主会话写）。

## 不做

- 派活说明的颜色（裁决 4，暂缓）；回复进气泡（裁决 5）；折叠头后面的步骤写法、中途提问留在外面（票 02）。
- 助手对话的任何变化。

## 验收

- 跑这几项：`pnpm --dir gui typecheck`、`pnpm --dir gui lint`、`TZ=UTC pnpm --dir gui test`，再用 `TZ=America/Los_Angeles` 全量跑一遍；`git diff --check`；全角标点自查（扫新增行）。gui 只格式化自己改的 hunk，新文件可以整篇格式化。
- **测试**至少覆盖：工作台你的消息靠右与宽度上限；悬停复制在气泡下方、隐藏时占位；时间居中与断点（含 Supervisor 消息、分页页前比较）；一步的运行没有折叠头与 StrongHr、两步的有；没有回答的运行照旧平铺；助手对话不变。
- **反向检查**：改坏几处，确认测试会挂；恢复后逐字节一致。例如：工作台回到左边、一步的运行又有折叠头、时间回到气泡上方、复制钮回到气泡右侧。
- **逐像素**：助手对话（静止、在跑、在问你、过程卡片展开；浅色与深色）与开工时的 main 一致。
- **自查截图**（Chrome harness，不进仓库）：工作台短对话、带折叠长消息的对话、在跑、在问你与答完、Supervisor 消息、子任务（「来自主对话」图标）、外置运行时；默认窗口、小窗口（问题轨与气泡的间距）、宽松档；浅色与深色、中英文；悬停你的气泡时的复制钮；一步与两步的回复；出总览图。
- **JC 在 tauri dev 里走一遍**：
  1. 打开一个工作台老会话，看你的话在右、时间在中间、悬停你的话复制钮在下方右侧；
  2. 找一个一步就答完的回复，看上面没有「1 步 · 用时」，悬停回复时 token 与上下文还在；
  3. 新问一句会调工具的问题，看在跑时照旧、跑完折叠头照旧；
  4. 把窗口拖窄、切到宽松档，看问题轨的点不贴气泡；
  5. 从助手点一个子任务卡片进去，看两边你的话都在右、时间都在中间；
  6. 打开助手，看助手对话没变。
