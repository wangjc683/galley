# 02 组内只显示最近 5 条 + 书眉「项目」改为新建项目

Status: done

来源：2026-10-09 JC 场景「同时开着三个项目、每个都有会话在推进，历史会话多时小屏找不到那三条」；
讨论与裁决见 [10-08 devlog](../../../docs/devlog/2026-10-08-sidebar-project-groups.md)。纯 GUI，Core / CLI / Agent API
零变化，外置 / 内置两种运行时一致。

## X　组内最近 K 条（JC 定，K = 5）

- 组的抽屉显示该项目最近 5 条会话（未归档、未置顶，按最近活动），其余收进尾行「更早 N 个」；分界从「30 天」改为
  「第 5 条之后」。分区列哪些项目仍按 30 天窗口（不变）。
- 展开且尾行收着时，尾行里需要你处理的（出错 / 等你回复）与选中的会话借位挂在尾行上方（此前只借位选中的）。
- 组行汇总、折叠时挂出、归档全部对话的范围都不变。

## A　书眉「项目」→ 新建项目 + 分区末尾「其他项目」（JC 按推荐，真机切换器定）

- 书眉与窄宽回落态的「项目」图标点了直接打开新建项目（`FolderPlus`，提示「新建项目」），不再是菜单。
- 30 天窗口外、未置顶的项目（原先只能从菜单找到）进分区末尾一行「其他项目 N ›」（组内尾行同款），点开就地展开成
  普通组行；展开状态只在本次运行内记住。
- 这一行收着时，其中项目里需要你处理的与选中的会话挂在它下面（同分区折叠时的挂法）；分区折叠时一并挂在分区头下。
- 揭示请求（新建项目 / 查看项目）指向这些项目时，先展开这一行。
- 只剩这些项目时分区照样出现；分区头数字 = 列出的项目数，为 0 时不显示数字。
- 切换器两档：「直接新建 + 其他项目」/「菜单（现状，对照档）」。裁决后拆切换器与落选档。

## 测试数据（重造方法）

用 `core/target/debug/galley` 建「测试 · 近期 A / B」（各移进 8 条 7～30 天前、无项目、未置顶的会话）与「测试 · 沉底」（5 条
30 天前的会话）：`project create "<名>" --reason …`、`session move <id> --to=<project-id>`。移会话只改 `project_id` 与
`updated_at`、不改最后活动时间（`core/src/db/session.rs:925`），所以沉底项目真的沉在窗口外。测完 `project delete <id>`，
会话原样回到时间分组（删前核对项目名与会话 id）。注意侧栏只显示当前运行时的会话，库里数要按 `ga_runtime_kind` 过滤。
