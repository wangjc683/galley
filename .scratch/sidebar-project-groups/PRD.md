# 侧栏项目组：项目会话折进时间线，删掉项目视图

Status: done

2026-10-08 与 JC 讨论定方向（方案 C + 合一），JC「按建议推进」。

## 起因与依据

- JC 问：普通侧栏要不要只显示非项目会话，项目会话交给项目视图。
- 本机 workbench.db（只读）：160 个会话，1 个项目「v0.6.1 发版回归」19 个会话，全是
  10-07 CLI 代跑回归建的；近 7 天未归档 25 个里 19 个是它（76%）。JC 手建项目 0 个。
- 以后同形态会常见：Supervisor SOP 把复杂任务拆成「项目 + 2～4 个子会话」
  （`docs/integrations/galley-supervisor-sop.md:222`）。
- 直接隐藏（方案 B）被否：项目会话的运行中 / 等你回复 / 出错在默认视图里失明（「项目」
  图标无徽标，项目行不汇总状态）；破坏「选中行必在侧栏里」（`layout-and-chrome.md:190`）；
  两个视图都残缺。补齐这些的成本接近方案 C，信息却更少。
- 合一而不是 C + 项目视图并存：C 之后项目视图只剩「全部项目清单」和「只看项目」两样独有
  价值；前者是翻档案（05-13「侧栏是当前工作面，不是档案浏览器」），后者无使用证据。并存会
  让同一个项目抽屉出现在两处，撞 05-13「避免两种交互并存」。05-22 做项目视图的理由「同时盯
  几个项目」，时间线里同时展开几个组即可。

纯 GUI 改动，Core / CLI / Agent API 零变化；外置 / 内置两种运行时模式表现一致。

## 设计

### 时间线结构

- **D1　一个项目在时间线里只出现一次。** 组行的活动时间 = 该项目未归档、未置顶会话的最大
  `lastActivityAt`；没有会话的空项目回退 `createdAt`（沿用 `effectiveProjectActivityAt` 的
  口径）。组行按这个时间落进 今天 / 本周 / 本月，在桶内与普通会话行按活动时间交错排序。
  `project.pinned` 的组行进置顶区。组行活动时间落在「更早」的项目不在侧栏出现（它的会话照旧
  进「更早」入口与 EarlierDialog）。
- **D2　置顶的项目会话留在置顶区，作为普通会话行显示，不进组**（置顶优先于日期，
  `gui/src/lib/sessions.ts:98`）。项目的子会话全部置顶时，组行不出现。
- **D3　只有一个会话的项目也折叠（一律折叠）。** 切换器上另放「≥2 才折」一档。
- **D4　组内平铺，按最近活动排序，不再套时间分组。** 范围是该项目 30 天窗口内、未归档、未
  置顶的会话；窗口外的放在末行「更早 N 个」，点击就地展开。空项目展开显示现有的
  「+ 新建项目对话」CTA。
- 桶标题计数 = 该桶里的顶层行数（会话行 + 组行），即用户看到的行数。「更早」入口计数不变。
- 「时间线全空时从更早里补 10 条」（`backfillRecentSessions`）按顶层行补：补进来的可以是
  组行，项目会话照样折在组里。

### 组行

- 身份：Phosphor `Folder`（展开时 `FolderOpen` + `text-brand-strong`，同现有项目行）+ 项目名
  + 置顶时的图钉。**组行永远不用 `bg-selected`**：侧栏里恰好一行在说「你在这里」，那是选中
  的会话或新对话行（`layout-and-chrome.md:174`），展开态只靠 `FolderOpen` 表达。
- **D5　状态汇总**沿用会话行优先级：出错 > 等你回复 > 正在工作（含 Goal 运行中）> 未读 >
  空闲（`SidebarSessionRow.tsx:105`）。左侧 3px 状态条复用会话行的三种（running 呼吸 /
  waiting 琥珀 / error 红）；项目名在有注意力状态或运行时 semibold，与会话行同规则；进入
  注意力状态时文件夹图标做一次 `sidebar-state-pop`（挂载不 pop，同 07-05 规则）。
- 第二行（仅「双行」档）：只说最高优先级的那一种 + 总数，用会话行的词：
  「1 个出错 · 共 19 个」「1 个等你回复 · 共 19 个」「2 个正在工作 · 共 5 个」
  「1 个未读 · 共 4 个」；空闲时「共 19 个对话」。色调同会话行副行（error / warning /
  running / muted）。
- 行内动作：悬停显现 `+`（在项目里新建对话）与 `⋯`；右键菜单与 `⋯` 同一组：置顶 / 取消
  置顶、编辑项目、归档全部对话（D10）、分隔线、删除项目。
- **D6　组折叠时，需要你处理的子会话露在组行下面**：出错或等你回复的子会话作为普通会话行
  挂在组行正下方（缩进与展开后的子会话一致），正在工作与未读不露。
- **D7　选中的子会话在折叠组里时，同样挂在组行下面**，不自动展开组（同 10-03「更早」借位）。
  露出的行就是该会话唯一挂载的那一份：折叠组的抽屉里不再挂同一个会话，避免
  `data-session-id` 重复，让「选中行在侧栏外来时滚进视野」照常工作。
- **D8　展开 / 收起组不设项目上下文。** 只有组行 `+`、空项目 CTA、书眉项目菜单里的项目项
  会把新对话行变成「新对话 · 项目名」。
- **D9　展开状态只在本次运行内记住**，启动时全部折叠（切换器上另放「默认展开」一档）。
- **D10　组行菜单「归档全部对话」**：确认对话框写明数量；有运行中的，沿用
  `archiveRunningBody` 的口径说明归档不会停止它们。走现有 `archiveSessionsBulk`。项目本身
  保留。

### 书眉「项目」图标改成菜单

- 不再是 Project Review 开关，去掉按下态与「退出项目视图」。点击打开下拉菜单（同 10-04
  顶栏两个灯菜单的语域）：第一项「新建项目」；分隔线；全部项目，按
  `sortProjectsForNavigation` 排序，`Folder` + 名称 + 置顶图钉；没有项目时在「新建项目」下
  放一行 muted「还没有项目」。
- 点项目 = 在该项目里新建对话（`startProjectConversation`），同时在时间线里展开它的组
  （组在时间线里时）。沉到「更早」的项目，它的旧会话靠搜索 / 更早对话框找——这是删掉项目
  视图的已知代价。
- 窄宽回落态（三个图标回到新对话行）同样是这个菜单。

### 其他入口

- 新建项目完成（`App.tsx:832`）、「移到项目」提示里的「查看项目」（`App.tsx:865`）：改为在
  时间线里展开该组并滚进视野。新建的空项目按 `createdAt` 落在「今天」。
- 删除：Project Review 模式及其进出动效、活跃 / 更早项目分组、侧栏零项目 CTA、分组标题
  「+」、`PROJECT_ACTIVE_WINDOW_MS` / `projectReviewNowMs` / `projectViewOpen` 等只服务于它的
  状态与文案。命令面板「新建项目」不变；⌘N 清项目上下文不变。

## 待真机裁决（临时切换器）

| 维度 | 档位（默认在前） |
|---|---|
| 组行 | A 单行：图标 + 名称 + 右侧计数 / B 双行：第二行写汇总 |
| 折叠门槛 | 一律折 / ≥2 才折（单会话项目显示为普通会话行） |
| 默认 | 折叠 / 展开 |
| 演示状态 | 无 / 正在工作 / 等你回复 / 出错 |

「演示状态」只在 dev 下伪造时间线里第一个项目组最近一条子会话的状态，用来看汇总、状态条、
D6 露出；JC 本机的回归项目全是空闲态。

A 单行把组当容器标题（比 48px 会话行矮），B 双行把组当会话的同级行：这是「相对角色」
分歧，按惯例真机定。
