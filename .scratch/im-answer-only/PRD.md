# IM 回答里只有回答：撤掉过程入口

Status: needs-dogfood（2026-11-11 票 01、02 与入口层那一段合入；JC 当天验过 Telegram、飞书，没有问题；微信没验，Discord 验不验没说；记录在 [devlog](../../docs/devlog/2026-11-11-im-answer-only.md)）

来源：2026-11-11 JC 在 Telegram 点最近一条消息的「过程」，得到「过程已不在了（渠道重启过）」：「我现在考虑是要修复这个问题，还是直接去掉过程，让 Telegram 更有真人 IM 对话的体验，只剩下最终消息回复。」主会话读现状后给了甲（删入口）、乙（持久化）、丙（小补丁）三档，推荐甲；JC 逐条裁了六点。

前提：渠道只跑在内置内核上，外置零变化。IM 的对话照旧不进 Galley 库（宪法 Rule 4）。

## 诊断

- 「过程」按钮背后的步骤只存在渠道进程的内存里（Telegram `frontends/tgapp.py` 的 `_processes`，Discord `frontends/dcapp.py` 的 `self._processes`，各 256 条的 LRU），渠道一重启就没了。这是 [IM 打磨 PRD](../im-polish/PRD.md) 裁决 1 写明的代价，不是 bug，但当时估轻了。
- 重启有多频繁：维护者机器的渠道日志里，10-21 以来有记录的 16 天共启动 94 次，约每天 6 次（开发机偏高）；普通用户每次退出重开、每次更新也都重启渠道。按钮的寿命是「到下次退出 Galley 为止」，昨天的消息基本点不开。机制上必然，不是边缘情况。
- 点击量量不了：点击不写日志。JC 这次点是想试按钮可不可用。
- 10-21 的前提「IM 是唯一能看过程的地方，所以只能藏，不能删」把「有界面入口」和「看得到」混在了一起。渠道重启后，`runner/im_resume.py` 会从内核日志把完整的原生历史（含每步的工具调用与结果）装回 agent（`frontends/continue_cmd.py` 的 `restore` / `continue_inplace`），所以 agent 自己一直记得怎么做的，跨重启也记得。按钮做不到的事，问一句「刚才怎么查的」做得到。
- 按钮展示的本来也是模型每步写的摘要（60 字截断、最多 30 步），不是工具级记录。
- 四个渠道今天的样子：Telegram 按钮（内存）；Discord 按钮、ephemeral（内存）；飞书卡片里的折叠面板（不依赖内存，重启后照样能开）；微信末行「N 步 · 用时 X」，从 10-10 起就没有过程入口。

## 裁决（JC 2026-11-11）

1. **方向取甲：删掉过程入口**。回答下面什么都不挂；在跑时的状态消息照旧；想知道怎么做的就问。这是换通道，不是删信号：事后的过程从按钮挪到「问一句」。
   没选：乙 持久化（乙1 把步骤摘要写进渠道状态目录，越过 `im_resume` 自己画的「只存文件名，不存对话内容」那条线；乙2 只存日志指针、点击时从内核日志重建，新增一处日志格式耦合；两者都要在 tgapp、dcapp 各做一遍，是为一个展开入口新增持久状态，而内容 agent 本来就有）；丙 点到失效的按钮时摘掉按钮、提示改成实话（昨天的过程照样看不到）。
   认下的代价：问一句要花一轮模型，得到的是复述不是清单；用时不在模型上下文里，「N 步 · 用时 X」事后没处看；`/new` 之后之前的过程问不到；Discord 频道里问是公开的、还会触发一轮运行（原来的按钮是只有自己看得到的一瞥）；IM 与桌面有意分叉（桌面主对话保留过程卡片）。
2. **飞书也跟**：撤掉回答卡片里的「过程」折叠面板。代价是删掉一个没坏的东西；换来四个渠道一条规则。
3. **微信末行「N 步 · 用时 X」一并去掉**。
4. **不动的**：停止回执「⏹ 已停止 · N 步 · 用时 X」、提问消息的「⏸ 等你回复 · 已完成 N 步」一类、出错消息上面那行「N 步 · 用时 X」。它们是状态，不是过程。
5. **IM 入口层先不加**「用户看不到过程，问起照实讲」一句。先用真模型评测问一句的效果（票 02）；评测不过再回来定。
   **当天改为加**（JC：「同意」）：评测 12 次计分过 9 次，不过的 3 次都是「过程给我看看」问后重跑；加一段的对照 12 次全过。原文：「The user sees only your final reply, never your steps. Asked how you did something, or to see the process (过程), recount it in a few lines from what you already did; do not run it again.」放在入口层讲手机屏幕的那一段之后，`IM_PROMPT_BUDGET_BYTES` 1630 → 1821。主会话自己改的，没另开票。
6. **已发出去的旧按钮**：点了静默应答并摘掉按钮，照 Discord 旧「停止」按钮的先例。旧的飞书卡片里的面板在客户端里，照旧能开，不管它。
