## 问题

现在「让一个做完的项目从侧栏消失」有两条路，都不完整：

- 归档全部对话：对话可恢复，但项目还在（30 天内建的留成「共 0 个对话」空行）。
- 删除项目并同时归档（10-08 起）：项目没了，归档的对话日后恢复时回到时间桶，不再属于这个项目（`sessions.project_id` 外键置空）。

缺的是「项目连同对话一起收起来，恢复时整组回来」。

## 方案草图

- `projects` 加归档态（或 `archived_at`），项目归档时把未归档、未置顶的对话一并归档，`project_id` 保留。
- 侧栏分区与书眉菜单不列已归档项目；「已归档」对话框按项目分组，可整组恢复。
- CLI / Agent API 只增不改：`project archive` / `project restore`，`project list` 加字段。

## 待定

- 置顶的项目会话随不随项目归档。
- 恢复单条对话时，它的项目若仍是归档态怎么办（连项目一起恢复，还是对话落回时间桶）。
- 有了整体归档后，删除确认框的「同时归档」是否保留。
