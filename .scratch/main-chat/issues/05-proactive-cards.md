# 05（E）主动提醒卡片 + IM 出口

Status: 暂缓（2026-10-13 PRD 裁决 49：依赖的事项账本已撤；等 `docs/devlog/deferred.md`「主对话的跨段连续性」的信号出现后重新定范围）

来源：主聊天 PRD 裁决 10、16、27（2026-10-09、10-12）。依赖 01（账本有内容）、06（卡片组件）。票序最后。

## 目标

提醒不再是用户事先设定的闹钟：助理从事务和信息里归纳出可能需要提醒的事，主动以卡片出现在主聊天里。

## 范围

- **生成**：定时读账本与近期历史，产出候选提醒。触发时点初稿：每天早上 + 每段结束后（待定）。调度归 Core。
- **卡片生命周期**（裁决 10）：带依据；可接受 / 忽略；依据过时（已回复、已做完）自动收回；按内容去重；不进模型上下文，接受后才成为一条消息。
- **防吵**：每天上限（确定式，数值待定）。提醒错了或太频繁比没有更糟。
- **通知**：主动提醒不是人发起的轮次，也要通知（iOS PRD 裁决 17 的例外）。
- **IM L1**：不在电脑前时，主动提醒与子任务的「在问你」发到用户选定的一个 IM 渠道。「不在电脑前」用确定规则（参考 iOS PRD 裁决 17：主窗口关掉进后台运行模式）。
  飞书 / Telegram / Discord 能随时发给主人；微信长间隔主动发送没验过（10-10 只验过几分钟间隔），先照 10-10 的做法探针（[devlog](../../../docs/devlog/2026-10-10-wechat-conversation-ux.md)：停微信渠道、借 token 长轮询）。
  今天能主动发的只有委派会话的完成汇报（`runner/im_reporter.py`），定时任务结果到不了 IM。
- 只在内置。
