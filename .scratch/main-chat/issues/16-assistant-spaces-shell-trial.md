# 16 助手与工作台两个空间的壳：现状 / 乙 左上开关 / 甲 左侧图标栏

Status: ready-for-agent

来源：主聊天 PRD 裁决 60、61（2026-10-14，JC：「现在主对话还是在形式上太接近于普通会话，好像是一个顶置的会话一样……把它变成一个类似的 IM……习惯于之前 Galley 会话管理跟使用方法的还是可以像之前一样」；方案「整体满意」，壳的比法按建议推进）。依赖 08、06a。只改 GUI，不碰 Rust。

## 目标

先定「助手住在哪」：一个窗口两个空间，助手（主对话）与工作台（今天的 Galley）。这一步只比壳：两个空间怎么放、怎么切、徽标挂在哪。助手空间暂用现有对话画法，IM 画法（气泡、过程、日期条、输入框）是下一张票。

## 三档（切换器真机比，从最克制排起）

- **现状**（对照）：今天的 B′：主对话行在侧栏顶上，侧栏可收起。
- **乙 左上开关**：不加栏。红绿灯右边（macOS 从 88px 起，Windows / Linux 常规左边距）一个两段开关「助手｜工作台」，两个空间里位置一样。工作台里它占掉书眉字标的位置，三个图标落到书眉下一行（复用 `SidebarNarrowNavRow` 的形态）；助手空间里它在全宽顶栏的最左。
- **甲 左侧图标栏**（主会话推荐）：窗口最左一列，两个空间里都在。macOS 红绿灯在 `{16, 22}`、簇右缘约 68px，栏要宽到把红绿灯装在自己顶上（约 76–80px，按实测定，写进 Comments）；Windows / Linux 栏顶没有红绿灯。下面两项：助手（头像）、工作台（图标），图标下带小字标签（飞书式）；栏底放设置（工具簇里的齿轮在甲里移到这里）。

## 三档共用的部分（乙、甲）

- **只在内置运行时且有主对话时有两个空间**；外置运行时与没有主对话时，三档都和今天完全一样。
- **助手空间**：没有会话侧栏，主区开着主对话，对话列居中照现有阅读宽度。顶栏：头像、名字「Galley」，名字下一行写它此刻在做什么（在跑：照侧栏状态行的「第 N 步 · 摘要」或「思考中」；等你回复：「在等你回复」；出错照写；静止不写）；右边状态簇、工具簇照旧（甲里没有齿轮）。没有标题菜单。
- **工作台空间**：侧栏回到没有主对话时的结构（`Sidebar.tsx` 里 `sectioned` 为假的那条路：无主对话行、无「其他对话」分区头与底色，主对话与未升级的子任务不进列表），侧栏不可收起、没有侧栏开关（照外置运行时）。主区开着上次在工作台里开的那个会话；没有就是空的新对话。
- **头像**：先用一个简单的圆形标记（品牌色底 + Newsreader 斜体「G」，与书眉字标同字体），不引入图片资源；正式形象另定。
- **徽标**：
  - 助手：主对话的状态，按侧栏主对话行图标的优先级（出错 / 子任务出错 > 等你回复 / 子任务在问你 > 未读）；在跑不挂徽标（顶栏那一行已在说）。
  - 工作台：有会话要你处理（出错、在问你，`useSessionsAttention`）；在跑不挂。
  - 只在徽标所在空间不是当前空间时显示。
- **切换**：点开关或图标；新加一对快捷键前先查冲突，查不出干净的就这一步不加，写进 Comments。
- **两边怎么连**：
  - 子任务卡片点开：切到工作台、打开那个子任务，顶栏面包屑「助手 ›」（原「主对话 ›」），点它回助手空间。
  - ⌘K：选中主对话去助手空间，选中别的会话去工作台；⌘N 新对话属于工作台，按了切过去。
  - 侧栏里不再有主对话行，所以工作台里回助手只走开关 / 图标栏与面包屑。
- **启动**：落在上次用的空间；没有记录时落在助手。试验阶段记在 localStorage，定稿再进 Core prefs。

## 验收

- `pnpm --dir gui typecheck`、`pnpm --dir gui lint`、`TZ=UTC pnpm --dir gui test`、`git diff --check`、全角标点自查；gui 只格式化自己的 hunk，新文件可整篇格式化。
- 测试：三档的显隐（外置运行时、没有主对话时都没有空间）；切换后的布局（助手空间无侧栏、工作台无主对话行）；徽标的来源与只在另一个空间时显示；子任务卡片切到工作台与面包屑回来；启动落点；问题轨在主对话不渲染、普通对话照旧。改坏一处（例如徽标在当前空间也显示、问题轨照常渲染）能被测试抓到。
- 自查：临时 harness 页在 Chrome 里截三档 × 两个空间（各带演示徽标与不带），浅色与深色、mac 与 Windows 的顶栏，量甲的栏宽与红绿灯余量、乙的开关位置与书眉回落，截完删掉。WebKit 由 JC 真机看。
- JC 在 tauri dev 里比，每档走一遍：
  1. 启动后看落在哪；在两个空间之间来回切几次；
  2. 在工作台打开一个会话，切到助手说一句，再切回来，看会话还在不在；
  3. 打开「演示」，看两边的徽标；
  4. 让助手派一个子任务（如「帮我开个子任务查一下厦门明天天气」），点卡片去工作台，再用「助手 ›」回来；
  5. 拉窄窗口到最小宽度，看两档的挤压。
