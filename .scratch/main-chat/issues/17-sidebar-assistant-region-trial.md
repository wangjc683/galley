Status: ready-for-agent

来源：主聊天 PRD 裁决 62、63（2026-10-14，JC 真机看过票 16 的甲、乙：「都不满意……应该还是让 Sidebar 来做这个切换，这样最简洁直观，而不是新增一个侧边栏。可能这个助理还是应该变成一个主要入口，在 Sidebar 上作为一个明显存在，然后再是新对话和下面的传统的 Galley 的对话区域」；侧栏的比法按建议推进）。依赖 16。只改 GUI，不碰 Rust。

## 目标

侧栏分上下两块：上面是助手入口，要一眼看出是「一个人」而不是「一行会话」；下面是「＋ 新对话」与原来的会话列表。比书眉、助手入口、新对话行怎么排。主区开着主对话时的 IM 画法是下一张票。

- **现状**（对照）：今天的 B′，原样。
- **方案 2 书眉就是助手**：红绿灯右边（macOS 从 88px 起，Windows / Linux 常规左边距）那块从字标变成助手入口：头像 + 「Galley」，单行，整块是一个按钮，主对话开着时用选中底色；状态（在跑、在问你、出错、未读）挂在头像上。书眉右边只留搜索。按钮之外的书眉仍是拖窗区。
- **方案 3 助手卡片**（主会话推荐）：书眉只留红绿灯与右边的搜索，其余整条是拖窗区；下面一张助手卡片：头像（约 32px）、「Galley」、名字下一行写它此刻在做什么；静止时只有名字，图标与名字垂直居中。卡片是侧栏里唯一带头像的东西，高度与留白让它自成一块，不读作会话行（具体做法你定，写进 Comments：边框、底色、圆角用不用，要守侧栏现有的选中三通道与 hover 语法）。
- **3′ 大头像**：同 3，卡片改成头像放大居中（约 48px）、名字在下、状态再下一行（参照 macOS「信息」侧栏顶上的置顶联系人）。

## 三档共用（方案 2、3、3′）

- **只在内置运行时且有主对话时生效**；外置运行时与没有主对话时，四档都与今天完全一样。
- **助手入口的状态**照票 14 的 A：在跑写「第 N 步 · 摘要」或「思考中」，在问你、出错（含子任务的两种）照写，静止什么都不写；有未读时头像挂标记、名字加粗。优先级照侧栏主对话行（`layout-and-chrome.md`「有主对话时」）。方案 2 放不下文字，只挂头像。
- **下面那块**：开头是「＋ 新对话 ⌘N」行（旧侧栏的新对话行），定时、新建项目两个图标在这一行右边；开着空白新对话时这一行亮着（「你在这里」恰好一处），取代票 13 的按下加号与「其他对话」分区头。下面照旧：项目、时间桶、「其他来源」，整块照票 09 铺 `bg-app`，吸顶与间距规则跟着新的开头行调整。
- **主对话行不再出现**；主对话与未升级的子任务照旧不进列表。
- **主区**：开着主对话时，顶栏左边是身份行（头像、「Galley」、它此刻在做什么），没有标题菜单；其余照旧。子任务的面包屑跟入口上的名字一致（「Galley ›」）。⌘K 里主对话也叫「Galley」（搜「主对话」「助手」仍能找到的话最好，做不到写进 Comments）。
- **侧栏照旧可收起**（B′、⌘\），收起后主区顶栏的侧栏开关照旧。
- **窄侧栏**：书眉、新对话行在侧栏最窄时怎么回落，按现有 `sidebar-width.ts` 的门槛思路重算，写进 Comments。
