## 二、为什么看不出来（裁决 119 第 2 条）

票 65 回报的数值：72px 上眼睛最多挪约 1.8px、头起伏约 1px、跳约 3px（`lib/assistant-face-motion.ts` 的 `MOTION`）；只动了眼睛和嘴，最大的部位舌头卷成的 G 从来不动；没用动画的基本手法。本票三样都改。

## 三、部位

图标是一个木头机器人：方形的头（左边一块竖着的侧板），两只圆眼睛，一张深色的大嘴，一条长舌头从头的右下方伸出去、绕一圈卷成 G，舌尖在右上角（斜切的头）。

1. **舌头当身体**：把描摹图（母图 `core/icons/master/galley-icon.svg` 的两条合成路径）在舌头的关节处切成几段（建议三到四段：根、中段、舌尖，你按形状定），每段绕关节转，做成一副骨架。**不重画**（票 23 重画过，不如描摹好看；做法照「描摹不重建」）。静止时与原图逐像素相同（照票 65 的验法：28 / 40 / 64 / 72 × 浅深，加载后与演完一拍后各比一次，最大差值写进回报）；动起来关节处的缝要处理到 2x 下看不出来，回报里给关节的放大截图。头也要能和舌头分开动（歪、转、弹、压扁拉长）。
2. **舌头的动作**：舌尖甩（上下摆，像狗摇尾巴）、整条卷紧与松开、往外伸长再缩回、软下来；头动时舌头慢半拍跟上，再晃两下停住（跟随）。
3. **眼睛**：圆眼、睁圆（最大约 1.8 倍）、眯成缝、笑眼 ^ ^、睡眼 ‿ ‿、用力 > <、出错的 ×（或打圈，你挑一个更好认的），位移可以扫满整张脸（72px 上约 ±5px）。
4. **嘴**：开合 0.2–2 倍，加大张、小 o、咧嘴笑。
5. **漫画符号**：「？」（在想、等你回复）、「！」（提醒叫醒、拖进文件）、「z z」（打盹，往上飘）、「✦」（做完）、汗滴（出错）。一次只出一个，72px 上 10–14px，放在头旁边、圆框外也可以；颜色跟主题（浅深各看一眼），不用红色（红色留给出错的字与徽标）。

## 四、幅度与手法（1 倍档的目标，72px 上）

| | 票 65 | 本票 1 倍 |
|---|---|---|
| 头的位移 | 约 1px | 6–8px |
| 歪头 | 3–7° | 12–20° |
| 跳 | 约 3px | 10–12px，跳出圆框 |
| 压扁与拉长 | 没有 | ±15–20% |
| 眼睛位移 | ±1.8px | ±5px，放大到 1.8 倍 |
| 嘴 | 0.3–0.85 | 0.2–2 倍 |

手法：起跳前下蹲（预备）、落地压扁再弹回、甩过头再回弹（缓动带回弹）、舌头跟随头慢半拍、主动作之外的次要动作（说话时舌头在嘴里也动）。时长可以比票 65 长一点，让大动作有分量，但干活状态「在动的时间 ≥95%、不停超过约 1 秒」、丙闲着「≤5%」照旧（裁决 117 第 8 条），回报重算占比。

## 五、各状态的夸张版（裁决 119 第 4 条）

| 状态 | 夸张版 |
|---|---|
| 在想 | 眼睛翻到左上角，头歪约 15°，舌尖慢慢卷起来（像手指敲下巴）；隔一会儿冒「？」 |
| 看网页 | 眼睛从左到右扫满整张脸，扫完一行「啪」地弹回，头跟着转 |
| 读文件 | 低头约 10°，眼睛贴底往下扫；舌尖隔几秒一翻，像翻页 |
| 记 | 头大幅点，像在本子上写；舌尖跟着画小圈 |
| 动手 | 整个身子压扁、弹起，一颠一颠；眼睛 > <；舌头像锤子一样甩 |
| 写回复 | 嘴大张大合，头随说话起伏，舌头在嘴里跟着动 |
| 派出子任务 | 舌头往外伸长，像递东西出去，再缩回 |
| 等子任务 | 左右张望；舌尖一下一下点，像等得不耐烦 |
| 你发出消息 | 预备后大幅点头、眨眼，舌尖甩一下 |
| 你在打字 | 身子朝输入框那边（右下）倾，眼睛睁圆，舌头不动（在听） |
| 鼠标移上去 | 弹一下、眼睛睁大、舌尖甩 |
| 拖进文件 | 「！」，眼睛睁到最大、嘴小 o，跳一下 |
| 按停止 | 动作当场停住、压扁一下、眨眼 |
| 做完 | 先下蹲，再跳出圆框，落地压扁；笑眼；舌头像尾巴一样甩；冒「✦」 |
| 等你回复 | 头歪约 20°，舌尖卷成问号的样子，冒「？」，然后定住看着你 |
| 出错 | 左右抖一下，眼睛变 ×，冒汗滴，然后低头、舌头软下来，定住 |
| 提醒叫醒 | 「！」，眼睛一下睁圆，弹起来 |
| 子任务交回 | 转头看回来、点头，舌头像接住东西一样收回 |
| 丙 · 没事时 | 照旧稀：偶尔眨眼、左右看（看的幅度变大），偶尔舌尖轻甩一下 |
| 丙 · 打盹 | 头慢慢垂下，闭眼，舌头微微耷拉出来，「z z」往上飘，身子随呼吸起伏 |
| 丙 · 醒来 | 「！」或眨两下，抬头，舌头收回 |

同一动作照旧备两三种变体、时机带随机，不连抽同一个；优先级与票 65 相同。

## 六、跳出圆框与顶栏

- 舞台 72 上，跳、舌头伸长、符号可以越过圆框（头像四周的留白够，写清楚给了多少、会不会盖到名字或「工作台」那一行）。选中时那圈品牌色描边照旧在圆上。
- 顶栏 28px：照旧裁在圆里，空间幅度按比例缩小（你定系数），不出符号；回报说清哪些动作在 28px 上保留。

## 要守住的

- 静止逐像素相同；`prefers-reduced-motion` 下脸不动、在跑时转圈徽标放回（票 65 的做法）；窗口不在前台时暂停。
- 外置运行时逐像素不变；生产构建照旧现状。
- 票 65 记过：Chrome 里 CSS / Web Animations 在跑时会把整张 SVG 错开半个设备像素，所以当时改用 SMIL。动作变大后可以重新评估，选哪种都要写理由，并在 2x 帧里确认一拍开始和结束时不跳。
- 性能：一个驱动，不逐帧跑 JS；动画只用 transform、透明度与 SMIL。
- `gui/` 不是 prettier-clean：旧文件只格式化自己的 hunk。React 编译器 lint：effect 里同步 setState、渲染期 `Date.now()` 都是 error；工具函数别从组件文件导出。动画的随机与时钟能注入，测试不靠真实等待。
