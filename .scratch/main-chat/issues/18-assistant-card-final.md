## 二、书眉与新对话行（裁决 64）

- **书眉**：红绿灯区（macOS 让出 80px，Windows / Linux 用常规左边距）加右边的搜索、定时、新建项目三个图标，也就是 `SidebarHeader` 去掉字标。按钮之外整条是拖窗区，非 macOS 双击最大化照旧；图标、提示、定时的徽标照 `SidebarNavIcons` 的 header 形态。
- **新对话行**：外置运行时那颗「＋ 新对话 ⌘N」按钮独占一行，是列表吸顶的第一行，铺 `bg-app`（票 17 的位置与间距可以沿用）。空白新对话的输入框开着时（项目的也算），整行用侧栏选中的三通道亮起，直到发出第一句、新会话行接替。
- **窄侧栏**：书眉放不下三个图标时，三个图标挪进新对话行（外置运行时现成的窄排法，见 `sidebar-width.ts` 开头的注释），跨过门槛时列表不上下移动。门槛、字与 ⌘N 何时让位，照 `sidebar-width.ts` 的写法重算并写出算式：mac 大约是 80 + 92 + 12 = 184px；Windows（8 + 92 + 22）与 Linux（8 + 92 + 12）在最窄的 134px 也放得下，没有窄态，但要核对 Ctrl+N 在窄宽度下放不放得下。

## 三、助手卡片：IM 列表的一行（裁决 65）

**结构**：头像 40px（品牌色圆盘和「G」照旧），名字「Galley」14px，名字右边是时间，第二行是最后一句或状态。卡片高度固定（约 58px，可以 ±2px，写进 Comments），第二行换内容时下面的列表不动。不加边框，静止时不铺底、不加阴影，悬停用 `bg-hover`，助手（或它的子任务）开着时用选中三通道，圆角 12px，这些都照票 17。卡片和会话行一样在按下（pointerdown）时打开，键盘的回车、空格照常可用。

**第二行**（一句话：第二行是它说的最后一句，有状态时写状态），优先级从高到低：

1. 出错：照旧（「出错」「出错 · N」，子任务的写「子任务出错」）。
2. 在问你：「等你回复：」用现在的琥珀色，后面接问题原文（`PendingAskUser.question`，纯文字一行），原文用第二行的普通颜色；取不到原文时只写「等你回复」。子任务在问你照旧写「子任务在问你」。
3. 在跑：照旧，「第 N 步 · 摘要」或「思考中」。
4. 草稿：助手没开着、它的输入框里有没发出的字或图时，「草稿：」用品牌色，后面接草稿的文字（只有图时写「[图片]」）。开着助手时不写：草稿就在输入框里，和未读同理。
5. 最后一句：这条对话最后一条看得见的消息，纯文字一行。
   - 去掉 markdown（标题、强调、行内代码；链接取文字；列表、表格摊成一行），空白合并；
   - 附件写「[图片]」「[文件] 文件名」，引擎回复里的 `[FILE:filepath]` 也写「[文件] 文件名」；
   - 是你说的，前面加「你：」（普通颜色）；
   - 第一次打开时就是问候那一行，它也是一条消息；
   - 切段标记、工具调用、步骤这些不是消息的东西跳过，判断不了的情形写进 Comments。

**时间**：第 5 条那句话的时间（没有消息时用会话的 `lastActivityAt`），放在名字那一行的右边，颜色与字号要安静（你定，写理由）。格式照 IM 列表：今天写「11:50」；昨天写「昨天」；再往前 6 天内写星期，如「周一」；今年更早的写「10月7日」；跨年写「2025年10月7日」。英文照 `message-time.ts` 的路子（Intl en-US：「11:50 AM」「Yesterday」「Mon」「Oct 7」「Oct 7, 2025」）。在 `message-time.ts` 里加列表用的格式函数并写测试；过了零点要刷新（侧栏已经有 `useDayStamp`）。

**名字与头像标记**：照票 17。头像右上角挂主对话行的状态图标（在跑转圈、在问你暂停、出错叉、未读实心点）；在跑、在问你、出错、未读时名字加粗，草稿与静止时不加粗。未读只在助手没开着时出现。

**字号**：第二行默认用会话行副行的规格（11px、行高 1.4、`ink-muted`）。放在 40px 头像旁边如果显得太小，可以用 12px，写进 Comments。

**数据**：只在界面里取，不改 Core。

- 主对话的消息在 `useMessagesStore` 的 `byId` 缓存里（启动就打开主对话）。不在缓存里时（例如还要引导配置模型、启动时没打开主对话），要能取到最新一页，但不激活它、不标已读、不动滚动位置。先找现成的读取路径；找不到就退回只显示名字和 `lastActivityAt` 的时间，写进 Comments。
- 草稿在 `gui/src/lib/composer-draft.ts` 的内存 Map 里，键是会话 id。加一个最小的订阅，让卡片跟着变，不改输入框的行为。

## 四、主区

- 开着助手时，顶栏左边是身份行（头像 28px、「Galley」、名字下一行写状态，照票 17）。整个身份行就是标题菜单的触发器：悬停与标题按钮一样，名字后面带标题按钮那个小箭头；点开是原来主对话标题菜单里的几项（`SessionTitleMenu` 在不能改名时的那些：重新注入工具、桌面宠物等），没有改名。
- 身份行的第二行照 IM 会话顶栏的写法：只写状态，即在跑（「第 N 步 · 摘要」或「思考中」）、等你回复（不接问题原文，原文就在下面的对话里）、出错与子任务的两种；静止时只有名字，不写最后一句，也不写草稿。它和卡片的第二行不一样，注释里写明理由。
