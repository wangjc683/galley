## 问题

JC：「其他对话」和下面的置顶 / 项目 / 本周 / 本月应该是从属关系，这一整块的统一性要加强。

根因（`gui/src/components/layout/Sidebar.tsx` 有主对话的分支）：主对话行与分区头包在同一个固定块里，分隔线画在这个块底下。
- 距离：分区头文字离主对话约 24px，离第一个子标签约 29px（块的 `pb-1` + 分隔线 + 时间桶标题的 `pt-3.5`）。
- 共同命运：分区头和主对话一起不动，列表在滚；一滚，分隔线恰好落在分区头与子项之间。
- 同类：分区头（12px semibold ink-soft）与时间桶标题（10px semibold 大写加字距 ink-muted）都是左对齐小标签，只差 2px。

## 三档（切换器真机比）

- **C1 基线**：只有主对话行固定在列表之上；分区头回到滚动列表里当第一行，吸顶（`sticky top-0`、不透明 `bg-chrome`、压在行之上），
  加号永远看得到，和子项一起滚。间距反转：分区头上方留大（与主对话分开），分区头到第一个子项留小（紧挨）。
  主对话与列表之间的分隔：先守「静止时不画分隔线、列表滚动后出线」（`docs/design/layout-and-chrome.md:173` 同类规则），线画在主对话下面；
  若静止时两块分不开，回报里说明并给数值，不要自行改成常显。占位行、空态说明都在分区头之下。
- **C2 = C1 + 子项缩进**：分区下的子标签（置顶 / 项目 / 时间桶）、会话行、项目组、其他来源组、「更早」入口整体右移约 8–10px，分区头挂在左边。
  回报具体数值与对 10-08 侧栏网格（标题 42px 列、18px 标签网格）的影响。
- **C3 = C1 + 整块底色**：分区头连同全部子项铺一层与侧栏底色略有差别的底（圆角或通栏由你定，回报理由），主对话留在原底色上。
  用现有 design token，浅色、深色两个主题都要可读；悬停与选中底色在这层底上仍要分得清（看 `globals.css` 的 `chrome-hover-scope` 怎么处理 chrome 上的悬停）。
