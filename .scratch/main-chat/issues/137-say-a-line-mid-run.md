# 137 先说一句：主对话在一轮中间先回你一句，不结束这一轮

Status: blocked（等票 136 合入：两张都改 runner 的事件、Core 的落库与 GUI 主对话的画法）

来源：[主对话 PRD](../PRD.md) 裁决 186 第 2 条（「少规矩、多手」的第二只手）。只在内置运行时的主对话；外置零变化。

## 为什么

- 有了插话改道（票 136），你的话在下一步就送到它面前；但 GA 一轮只出一个回复，它想先回你，只能把手上的交出去或结束这一轮。选项太少，它容易闷头做完，你还是在等。
- 真人助理边查边回你一句：「记上了，天气还在查」。

## 要做到（草稿，136 合入后细化）

1. 给内置 GA 加一个工具（托管补丁，按 `docs/managed-ga-runtime/README.md` 的补丁规则：最小、隔离、有文档、可重放），只在主对话里暴露：给用户发一句话，这一轮不结束、接着做。
2. Core 把这句落成主对话里的一条 Galley 消息，GUI 画成气泡；手机端照样收到。这一轮最后的回复照常落在后面。
3. 工具说明只讲它是什么、什么时候有用（用户在你干活时说了话，或者手上的事要做很久），不加规则。
4. 通知：这句算不算「回复完成」、发不发通知，设计时定，写理由。
5. 评测或测试：插话后它用不用这个工具、用了之后接着做的那一段对不对。
