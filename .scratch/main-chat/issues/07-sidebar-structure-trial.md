## B：骨架

```
Galley                    搜索 定时 新建项目
⌂ 主对话                  ← 不随列表滚动，启动即选中，A3 的轻重
旁聊                  +   ← 分区头，加号 = 新建（⌘N 同）
  置顶 / 项目 / 今天 / 本周 / 本月 / 更早
  其他来源 N              ← agent 开的、不在项目里的
```

- **主对话行**：沿用 A3（满墨色标题、启动即选中、无菜单）。还没发过第一句时，副行写「什么都可以跟它说」；之后副行照常显示状态摘要。
- **分区头**：比时间桶标题（10px）高一级，与它们明显区分；加号是图标按钮，提示「新旁聊 ⌘N」（随叫法）。
  分区头本身不可点、不折叠。
- **空态说明**：分区下没有人开的对话时，显示一行「单独聊一件事，主对话不受打扰」（随叫法调整措辞）；有了第一条就消失。
  先例：侧栏空列表的「你的对话会出现在这里。」（`gui/src/components/layout/Sidebar.tsx` 空列表分支）。
- **「你在这里」**：点加号进入空白新对话时，分区最顶上出现一条选中的占位行（「新旁聊」，随叫法），发出第一句后由真会话行接替，
  保持「侧栏永远恰好有一行在说『你在这里』」（`docs/design/layout-and-chrome.md:173`）。
- **谁算旁聊**（裁决 32）：分区里的时间桶只放人开的对话（`origin.via` 为 gui，含手机端）。agent 开的（CLI、supervisor、`system`、定时任务）：
  在项目里的留在项目组，不在项目里的收成一行「其他来源 N」，放在时间桶之后、「更早」之前。
  这一行的行为照 10-08 项目组：默认收起，可展开，收起时等你回复 / 出错 / 选中的会话挂在这一行下面（读 `docs/design/layout-and-chrome.md` 项目分区一节与 `SidebarProjectGroup.tsx`，复用而不是另写）。
  定时任务产出的会话今天带时钟徽标，06 之后会改为主对话卡片，本票先归「其他来源」。
- **窄宽回落**：三个图标放不下时落到书眉下单独一行（复用 `SidebarNarrowNavRow`），不动分区头。
- 置顶、项目、时间桶、「更早」、已归档的现有规则全部照旧，只是整体挪进分区里。

## B′：B + 侧栏可收起

- 收起后主对话占满窗口；再展开回到原宽度。收起状态记在 localStorage。
- 入口：主区顶栏最左一个图标按钮（展开 / 收起同一个），加快捷键。快捷键先查 `docs/design/` 与 `gui/src/lib/shortcuts*` 现有绑定，选不冲突的（候选 ⌘\ 或 ⌃⌘S），回报选了哪个。
- macOS 红绿灯：收起后主区顶栏要给红绿灯让位、保持可拖动（读 `docs/design/layout-and-chrome.md` 顶栏与 `data-tauri-drag-region` 的规则）。Windows / Linux 照同一规则。
- 收起时有旁聊在问你 / 出错：展开按钮上显示计数徽标（先例：书眉「定时」图标的待处理计数；不要状态点，`layout-and-chrome.md` 禁令）。
- 规则改动（「Sidebar 不可折叠」「不放 Sidebar toggle」，`layout-and-chrome.md:22`、`:71`）只在试验里生效，裁决后再改文档。
