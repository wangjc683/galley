## 为什么

勾掉一件今天的事，顶栏按钮上的「今天 N」一帧换成 N−1；最后一件勾掉时数字不见，按钮从带数字的宽度一帧收回 28px 的方块，它旁边的东西跟着跳。

## 要做的

1. **数字跳一下**：N 在挂载之后变了（多了、少了、从没有到有）的那一下，数字用 `sidebar-step-tick`（`gui/src/styles/globals.css` 现成的：淡入加上移 1px，`--motion-slow`）。挂载时、切会话带来的重新挂载不放。
2. **宽度走过渡**：按钮的宽度因为数字出现、不见、位数变了（9 → 10）或三种样子之间切换而变的那一下，从旧宽度走到新宽度，`--motion-base`、`--ease-firm`，顶栏里它旁边的东西跟着平滑让位。实现由你定（量前后的宽度再用 Web Animations，或别的办法）。真窗口在 macOS 上是 WKWebView、Windows 上是 WebView2，两边都要行：不许用 `interpolate-size`、`calc-size()` 这类 WebKit 还没有的 CSS。宽度走的途中字不换行、不被压扁（裁掉可以）。
3. **数字不见的那一下**：数字跟着宽度收回时淡出或被裁掉都行，不能先一帧不见、再收宽度。
4. **与接住卡片的 pop 不打架**：卡片飞进来、按钮 pop（`todo-catch-pop`，主聊天票 102、104）的同时数字也可能变（记下一件今天到期的事）。pop 的规则不改（胶囊时只弹图标）；两样落在不同的元素上、同时走，不排队。做下来有冲突写进回报。
5. **减少动态**（`prefers-reduced-motion`）：宽度一步到位；数字只淡不移（`sidebar-step-tick` 现在在减少动态下还移 1px 的话，给这一处补成只淡）。
6. 静止时的样子与现在逐像素相同。选中底色、悬停、无障碍名、悬停提示的规则不变。

### 2026-11-11 主会话验收

- 读了组件与 hook 的 diff；rebase 时 `globals.css` 与票 160 在同一处各加一段，两段都留。合入前在票的工作树里跑门禁：`typecheck`、`lint` 通过，`TZ=UTC` 测试 276 个文件、3169 个全过，文档链接与 `git diff --check` 干净。
- 做法：宽度用 Web Animations 走按钮自己的 `width`，旧宽度取上一次排好时的（ResizeObserver 跟着，窄顶栏让位时组件不重画），途中临时加内联样式（裁掉溢出、不换行），走完全撤；数字与胶囊上的「+N」用变化次数作 key 重放 `todo-count-tick`。
- **票面前提不对的一处**：`sidebar-step-tick` 在减少动态下不是「还移 1px」，是整个不动；新类 `todo-count-tick` 在那里只淡。
- **验收后追加**（主会话退回，代理第一轮报的风险）：胶囊变成图标或带「待办」两个字时，胶囊的正文和细线框原来第一帧就没了，只剩图标在 160ms 里滑过约 150–190px，而这是最常走的路（今天最后一件勾掉）。改成正文留在原处、跟着宽度裁掉并淡出，细线框与圆角留在按钮上跟着宽度走（边线淡到新样子的颜色、圆角 14px 走到 6px）；变成「待办」时那两个字在原来正文的位置淡入（代理加的，不加两段字会叠在一起）。反方向细线框第一帧就在，标题途中只被裁、不加省略号。
- 没在真窗口量过的（代理原样）：
  1. 宽度在 WKWebView 与 WebView2 里是否连续走、开头结尾有没有闪一帧。
  2. WebKit 里 `getComputedStyle(width)` 对 inline-flex、border-box 的按钮是否返回边框盒宽度。
  3. 窄顶栏让位之后再勾，起点是否取对。
  4. 途中英文 To-do 与中文「待办」不换行。
  5. 离开的数字、离开的正文淡出加裁掉的观感；离开的正文（绝对定位，左 25px、垂直居中）与原来的正文是否逐像素重合。
  6. 边线颜色与圆角能不能用 Web Animations 平滑地动。
  7. 「待办」淡入时与正在淡出的正文叠在一起的观感。
  8. 面板开着（选中态）时框留在原样、只有圆角在变。
  9. 减少动态下只淡不移；静止时逐像素相同。
- 没解决的（代理原样）：胶囊收回走到一半样子又变时，框从当时的颜色与圆角接着走，正文的宽度沿用第一次设的；没专门测。
- 票外发现（原来就有，没动）：按钮在 N 出现、消失或样子切换时 React 重写 className，会把正在播的 `todo-catch-pop`（用 classList 加的）冲掉；飞行的终点在起飞时量，起飞后按钮变形落点会偏。
