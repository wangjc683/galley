# 06（F）子任务：父会话、派活标签、卡片

Status: 拆为 [06a](./06a-subtask-dispatch-and-cards.md)（派活与卡片，done，2026-10-13 合入）、[06b](./06b-scheduled-results-as-cards.md)（定时任务改卡片，needs-triage）

来源：主聊天 PRD 裁决 5、9、25、26（2026-10-09、10-12），派活方式由裁决 52（2026-10-13）改为回复里的标签。依赖 02。卡片组件在本票做出来，05 复用。

## 目标

主聊天派出去的活不占住主聊天，也不往侧栏里塞行：主聊天里一张卡片，需要你时浮到你面前，你在里面说过话它才算你的对话。

## 范围

- **父会话**：`sessions` 表加父会话字段（迁移 + 六处手写列表）；CLI / Agent API 只做加法（Rule 3）。
- **派活标签**（裁决 52，取代裁决 5 的原生工具）：主对话在回复末尾写 `<subtask>要做的事</subtask>`，Core 在这一轮结束后开子任务。界面藏起标签；回放时把说明换成一行带子任务编号的标记，模型问起时用 CLI 按编号查。
  主聊天入口层的派活条款要求用它，不用 GA 的文件式子代理（`memory/subagent.md`：后台进程靠 input / output 文件通信，Galley 看不见，没有卡片、没有「在问你」、手机也看不到；对照里模型会主动去读它）。条款草稿与对照结果见 `.scratch/main-chat/entry-layer-eval/`。
- **卡片**（一次派活一张）：在跑一行进度；在问你卡片里直接答；完成一行结果 +「打开」；失败原因 +「打开」。
  浏览器活显示「已看 3 / 7」与网站图标，复用 10-04「对话显示网站」。GA 浏览器不能并行（`memory/subagent.md`），多个网页是一个子任务依次看。
  能并行的活合成一张卡，展开看每个。卡片不进模型上下文，模型只在用户问起时用工具去查（裁决 9）。
- **侧栏**：子任务默认不进侧栏。打开在主区，顶上「主聊天 › 标题」面包屑返回；侧栏选中停在主聊天（「选中行必在侧栏里」，`docs/design/layout-and-chrome.md:189`）。
  子任务在问你时，状态亮在主聊天行上。
- **升级为旁聊（确定式）**：用户在子任务里发过一句话，它就升为旁聊进侧栏。
- **通知**：只发「在问你」与跑得久的完成。
- **定时任务改卡片**（裁决 26）：定时任务的结果是主聊天里的卡片，产出的会话按子任务处理、不进侧栏（今天进普通时间线带时钟徽标，`gui/src/App.tsx:437-438`）。
- 只在内置；外置模式的定时任务与侧栏照旧。
