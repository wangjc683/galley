# 37 界面：提醒卡片、「定时」列表、送不出去的通知

Status: ready-for-agent

来源：[助手 PRD](../../assistant/PRD.md) 裁决 9，主对话 PRD 裁决 84。依赖 33（字段与事件）。只改 GUI。

## 目标

它建了提醒，你在它那条回复下面看到一张从库里画的卡片，能一键取消；「定时」里看得到它替你记的全部事；到点叫醒送不出去时有系统通知。

## 一、提醒卡片（只在助理的对话里）

- 挂在建它的那条回复下面（票 33 记下的会话与 `turn_index`），挂法与位置照子任务卡片（`docs/design/conversation.md:114`：紧贴气泡下 12px，在行动条之前，最宽同气泡上限）；同一条回复建了几个就几张，和子任务卡片同在时先子任务后提醒（或你定、写理由）。
- 形态借子任务卡片（hairline、`rounded-md`、`bg-app`），一行为主：时间（本地；今天、明天、周几加时刻，远的写日期；重复的写规则，如「每天 8:00」）、它记下的话（一行省略）、状态、「取消」。
- 状态：待提醒 / 已提醒（一次性触发后）/ 已取消 / 已停用（重复的）。取消后卡片留着、写「已取消」，不消失（照票 33 的软删除）。
- 「取消」一点就取消，不弹确认（只波及这一件、它也会在对话里知道）；失败就在卡片上写一行原因。取消后不通知它（它下次看「在办的事」会知道）。
- 主对话在跑时卡片照常可点。
- 不做切换器：形态照子任务卡片，JC 真机看；他要比再加。

## 二、「定时」列表

- 现有的管理对话框（scheduled-tasks 票 04）：
  - 列出一次性的（绝对时刻、已触发的单独一组或排后）与重复的；标出「到点做什么」（叫醒助理 / 新开会话）与谁建的（助理建的给一个小标记，文案你写，照文案规范）；已取消的默认不列。
  - 每行能取消 / 删除、启停（重复的）；已有的编辑表单照旧能改。
  - **托管运行时、有主对话时**：「新建」入口换成一句引导（大意「跟助理说一句就行」，举一个例子）和一个打开助理的按钮；外置运行时照旧是表单（那边没有助理）。空状态的示例（票 09）同理。
- 侧栏「定时」入口照旧。

## 三、叫醒

- 票 33 的新报告行在页面上藏起来，规则照票 31（按 supervisor 认）；确认手机端的转发与渲染规则不受影响（远程协议照旧转发，按来源藏）。
- 送不出去的事件：发系统通知，标题写「提醒」或任务的第一句，正文是它记下的原话；点通知打开助理。照子任务送不出去时的通知做法（票 31）。

- 测试：卡片各状态的渲染；取消调用对的命令；工作台与外置不画卡片；列表的分组、标记、托管下没有新建表单而外置有。
