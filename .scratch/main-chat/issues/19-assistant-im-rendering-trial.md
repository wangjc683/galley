# 19 主区的 IM 画法：气泡 / 过程 / 时间 / 滚动

Status: ready-for-agent

来源：主聊天 PRD 裁决 66（2026-10-14，JC 按建议推进：「我们来讨论主对话的 IM 化改造，之前这个 session 你有提到的一些方向我就觉得不错」）。方向见裁决 60（助手像 IM，工作台照旧）、65（侧栏卡片是 IM 列表的一行）。依赖 18。只改 GUI，不碰 Rust。

## 目标

助手开着时，主区要读起来像和一个人的长期 IM，而不是工作台的任务记录。四件事各做成可切的档，在 tauri dev 里真机比；比完按赢家定稿，另开票。输入框放第二轮（裁决 66 第 5 条）。

## 生效范围

- 只在内置运行时、主区开着助手时生效（`MainView` 的 `isMainChat`）。工作台的会话、从助手点开的子任务、外置运行时，任何档下都与今天完全一样。
- 四件互相独立，任意组合都要能看（比如 C 气泡配现状的过程）。

## 四件（每件从最克制排起）

### 1. 气泡：现状 / B / C

```
现状                         B                            C
┌──────────┐                           ┌──────────┐                 ┌──────────┐
│ 你说的话  │                           │ 你说的话  │                 │ 你说的话  │
└──────────┘                           └──────────┘                 └──────────┘
它的回复是散文，满栏……         它的回复是散文，满栏……       ┌──────────────┐
                                                              │ 它的回复       │
                                                              └──────────────┘
```

- **现状**（对照）：你的话是左对齐的杏沙气泡（`gui/src/components/conversation/MessageUser.tsx:342`），它的回复是不加框的散文。
- **B**：只把你的气泡挪到右边，宽度随内容、有上限（比例你定，写进 Comments）；回复照旧是散文。
- **C**（主会话推荐）：两边都是气泡。你的在右，杏沙，底色与圆角同现状；它的在左，中性底色，从现有 token 里挑、不新增颜色，浅色与深色下都要和杏沙、页面底分得开；圆角与你的同档。都不加边框、投影、小尾巴（`docs/design/conversation.md:34` 的后三条照守）。
- **B、C 共用**：
  - 消息里不放头像，也不写名字。
  - 同一边连着几条时间距收紧（IM 的分组），换边时恢复。数值你定。
  - 复制入口、`line-clamp-6` 折叠、附件缩略图、`data-role`（⌥↑ / ⌥↓ 靠它跳）跟着气泡走；你的气泡在右时，悬停出现的复制按钮挪到气泡左侧外面。
  - 宽屏模式（1200px 栏）下气泡也有宽度上限，不能撑成一千像素宽。
- **C 另有**：
  - 它的字体照旧 Newsreader，markdown 排版（列表、行内代码、标题）照旧，只是装进气泡；选中文字后的浮动复制照旧可用。
  - 回复的行动条（复制、保存，悬停时出现）放在气泡下面。
  - 表格、代码块、图片在气泡里怎么放你定：宽表格可以在气泡里横向滚动，也可以让气泡撑满栏宽；代码块要避免读成「框里套框」（比如在气泡里换底色）。做法写进 Comments，截图里要有。
  - 它问你的问题（`AskUserBubble`，在问你时与答完后的回显）是一条普通的左侧气泡，候选照旧排在气泡下面；不再用黄色竖条和「等你回复」字样（侧栏卡片与输入框占位已经在说）。
  - 子任务卡片（`renderAfterAnswer`）跟在派活那条回复的气泡下面，左对齐。
  - 问候是一条普通的左侧气泡。

### 2. 过程：现状 / 一行

- **现状**（对照）：每条回复上面一行折叠头「N 步 · 用时……」。人发起、跑完的运行一律折叠，不看步数（`gui/src/lib/run-groups.ts:243`），一步就答完的也有「1 步」。在跑时是 live 窗口、思考行、三行思考预览、流式正文，右下角还有计时。
- **一行**（主会话推荐）：
  - **在跑时**：对话末尾、它那一边只有一行，写这一轮里它最近写出的一句话。这句话是步骤的旁白，第一人称，例如「我查一下这周末的气温、降雨和风力。」；正在流出的也算，取那段文字的第一行。还没写出任何话时写「思考中」。一行放不下就截断。超过 3 秒后在后面带上这一轮的计时（与右下角计时同源、同格式）；这一档里右下角的计时不显示，只留一处。不列步骤，不显示思考预览，不流式显示正文。这一行要看得出它在忙（照现有思考行的 shimmer 或类似的安静动效，你定），不做三个点的打字气泡。
  - **回复出来**：这一轮落定（最后一步是回答）时，这一行消失，回复整条出现（C 档里是一条气泡）。不要用启发式去猜「正在流出的这段是不是回复」，JC 要确定的规则；所以长回复要等写完才整条出现。这是已知代价，写进风险。
  - **落定后**：两步以上的回复，在回复下面留一个安静的入口「9 步 · 用时 1 分 21 秒 ›」，只要结构那一段，不要工具的气味。点开就在入口下面原地展开这一轮的步骤区（现有 `RunFoldSection` 里的内容），再点收起。一步就答完的什么都不留。
  - **提问与回答是对话**：它中途问你的那条（`ask_user`）和你的回答，落定后也留在外面，按时间顺序与其他消息一样显示（气泡档里就是两边各一条气泡），不折进步骤；展开的步骤区里不重复它们。
  - **在问你时**：这一行不显示（它在等你，不在忙），提问照第 1 件的画法。
  - **没有回答的运行**（中止、出错、停在步数上限）：照现状整段展开，出错提示与步数上限的续跑照旧。
  - 子任务卡片照旧跟在派活那条回复下面。

### 3. 时间：现状 / 居中

- **现状**（对照）：断点处的用户消息上方一行，左对齐。断点是第一条用户消息、与上一条用户消息隔 60 分钟以上、跨天、Supervisor 来源（`docs/design/conversation.md`「发送时间」，`gui/src/lib/message-time.ts`）。
- **居中**（主会话推荐）：断点规则与格式都不变，改成两条消息之间居中的一条，属于整段对话，不贴在你的气泡上。问候是对话的第一条，它上面也给一条；问候的时间拿不到就不给，写进 Comments。字号与墨色照现有时间行，不加底色胶囊（iMessage、微信都是居中的浅色小字）；悬停给完整时间照旧。
- 不做：每条消息带时间、悬停才出现的时间（JC 09-28：「有点吵，也没有必要」）。

### 4. 滚动：现状 / 贴底

- **现状**（对照）：发出后你的话顶到视口顶部下方 32px（`docs/design/conversation.md:354`）；在底部时流式跟随。
- **贴底**（主会话推荐）：
  - 对话不满一屏时，消息贴着输入框往上排，而不是从顶上往下排（重置后只有问候时，它就在输入框正上方）。
  - 发出后滚到底：你的话出现在输入框正上方，它的那一行（或现状档的过程）在下面。
  - 回复长出来时跟着走（照现有规则：在底部才跟，往上翻过就不跟）；但不能把这一轮回复的开头推出视口。开头快到视口顶部（留 32px）时停止跟随，「回到底部」按钮照现有双态信号出现。一行档里回复整条出现，长回复出来时停在它的开头，不滚到它的底部。「回复的开头」指你的话后面的第一样东西。
  - 切换会话、打开助手时照旧落在底部；往上翻加载更早的页照旧不跳。

## 切换器

- 常驻 pill「临时 · IM 画法」，四组各自切：气泡（现状｜B｜C）、过程（现状｜一行）、时间（现状｜居中）、滚动（现状｜贴底）。另有两个快捷「全部现状」「全部推荐」（C、一行、居中、贴底），和一组「演示」（关｜静止｜在跑｜在问你）。
- 组多、一行放不下时，可以收成 pill、点开是小面板，你定；要求是常驻、点得到，不压住顶栏按钮、输入框和「回到底部」按钮。portal 到 body，`pointer-events: auto`。
- 默认全部现状、演示关。选择记在 localStorage（`galley.tmp.imTrial.*`，读写都包 try/catch）。只在内置运行时、主区开着助手时出现。
- 删除步骤写在试验模块的头部注释里；试验测试单独一个文件，定稿时把赢家的用例并进正式测试。

## 演示对话

JC 的主对话今早刚重置，只有 4 问 4 答，看不出长对话的样子。「演示」打开时，主区换成一段固定的演示对话：只换显示，不写库、不改 store 里的真数据、不发给模型，关掉就回到真对话。演示打开时，输入框发出的消息不能悄悄进了真对话却看不见：禁用发送，或在输入框上写明「演示中」，你定，写进 Comments。

内容中英两版，按界面语言选；全部合成，不用 JC 的真实对话：

- 问候开头；跨三天（前天、昨天、今天），出现跨天、隔一小时以上的断点。
- 短问短答（十几个字）；约 280 字带列表的回复；约 400 字带表格的回复（4 列以上，看宽表）；带代码块的回复。
- 多步的回复（比如 9 步，每步一句第一人称的旁白）与一步就答完的回复，用来看「N 步 ›」入口有和没有。
- 一轮里它问你（3 个候选），你选了一个，它接着回答。
- 一条派了子任务的回复，下面挂子任务卡片（在跑一张、完成一张）。
- 你发的一张图片（附件缩略图），以及连发的两三条短消息。
- 「在跑」：末尾模拟一轮正在跑，那一行每几秒换一句旁白，计时在走。现状档的 live 窗口与思考行如果要 store 状态、模拟不全，可以简化，写进 Comments（JC 也会发真消息看）。
- 「在问你」：末尾是一条等你回答的提问，带候选。

## 不做

- 输入框（第二轮）；头像与形象；叫法；Core、库、CLI；手机端。
- 工作台会话、子任务、外置运行时的任何变化。
- 设计文档不改，定稿票再改。

## 验收

- `pnpm --dir gui typecheck`、`pnpm --dir gui lint`、`TZ=UTC pnpm --dir gui test`，时间相关的测试再用 `TZ=America/Los_Angeles` 跑一遍，`git diff --check`，全角标点自查。gui 只格式化自己的 hunk，新文件可以整篇格式化。
- 测试（试验测试单独一个文件；能抽成纯函数的抽出来测）：
  - 只在主对话生效：普通会话、子任务、外置运行时在任何档下都与今天相同。
  - 气泡：B、C 的对齐与气泡；C 里提问和问候都是气泡；子任务卡片在回复下面。
  - 一行：在跑时只有一行；文字取最近写出的那句；3 秒后带计时；右下角计时不显示；落定后两步以上有入口、一步的没有；点开能展开；提问与回答留在外面、展开后不重复。
  - 居中：同一套断点；问候上面有一条。
  - 贴底：短对话贴着输入框；发出后滚到底；停在回复开头。
  - 反向检查至少四处（例如一步的回复也出入口、提问被折进步骤、普通会话也换成气泡、居中档丢了一个断点）：改坏后确认测试挂掉，恢复后逐字节一致。
- 「全部现状」与开工时的 main 逐像素一致：同一个 harness，在主对话、普通会话、子任务、外置运行时各几个画面（静止、在跑、在问你）上比，藏掉切换器。
- 自查截图（Chrome harness）：四件各档 × 演示静止，浅色与深色、中英文、默认窗口（1480×920）与小窗口（960×600）、宽屏模式各一组；一行档与现状档的在跑、在问你。量出气泡的宽度上限、两边的间距、分组间距、时间条的位置。拼几张总览图。截完把 harness 从工作树删掉。WebKit 由 JC 真机看。
- JC 在 tauri dev 里比：
  1. 打开「演示」，先点「全部现状」再点「全部推荐」，来回看整体；
  2. 四件各自切，看哪一件最让它像 IM、哪一件不舒服；
  3. 关掉演示，在助手里发一句要查一会儿的话（如「查一下厦门明天天气」），「过程」两档各看一遍在跑与落定；
  4. 发一句短的（如「谢谢」），看「滚动」两档发出后的位置；
