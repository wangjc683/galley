## 路径（JC 在 `pnpm --dir gui tauri dev` 下跑）

1. **自行完成**：一个有可验证终态的小目标（例：「把 X 目录下三个 md 的标题
   统一成 sentence case，逐个核对」），上限 30。预期：若干轮后模型打
   complete，收口标记「✓ 已完成 · 用时 · 续跑 N 轮」，通知一次。
2. **到达上限**：开放式目标（例：「持续改进这篇文案」），上限 30 秒级的
   测试值（实施时给 dev 环境留 `--budget-minutes` 小数或秒级隐藏参数）。
   预期：上限后一轮收尾，收口「⏱ 到达上限」，latestSummary 是收尾内容。
3. **进行中停止**：pill 点停止。预期：当前 run 立即中止，收口「⏸ 已停止」，
   无收尾轮。
4. **中止后恢复**：Composer 停止按钮中止当前 run。预期：pill 变「已暂停」，
   线程尾「Goal 已暂停 · 发消息继续」；发一条纠正消息，跑完后自动续跑，
   pill 回「运行中」。
5. **受阻**：目标依赖一个拿不到的东西（例：读一个不存在的 URL）。预期：
   模型三轮后打 blocked，pill「受阻 · 需要你介入」，尾标带说明；发消息
   提供所需即恢复。
6. **attach 模式**：路径 1 在 external GA 上再跑一次，确认标签遵从与展示
   剥离。
7. **Core 重启**：goal 运行中退出并重开 Galley。预期：pill「已暂停」，无
   后台续跑。
8. **两个 session 各一个 goal** 同时跑：pill 列表两条，互不影响。
