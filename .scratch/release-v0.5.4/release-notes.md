## What's New

- Your messages show their send time at the start of a conversation and after a gap of more than an hour (for example `Yesterday 9:14 PM`); Supervisor messages always show it.
- The toolbar under each answer (copy, save, token and context usage) appears only while you hover over that answer.
- The sidebar's top shortcuts fit on one row: New chat keeps its label, while Search, Scheduled and Projects become icons with their names and shortcuts in tooltips; New project moves to the Project Review group header.
- In English, the action that starts a conversation is now called "New chat" everywhere it appears.

## Installation Guide

### macOS

- [Download for Apple Silicon](https://github.com/wangjc683/galley/releases/download/v0.5.4/Galley_0.5.4_macOS_aarch64.dmg)
- [Download for Intel](https://github.com/wangjc683/galley/releases/download/v0.5.4/Galley_0.5.4_macOS_x64.dmg)

If macOS says Galley cannot be opened, run this in Terminal:

```bash
xattr -dr com.apple.quarantine /Applications/Galley.app
```

### Windows

- [Download for Windows](https://github.com/wangjc683/galley/releases/download/v0.5.4/Galley_0.5.4_Windows_x64-setup.exe)

If Windows SmartScreen shows a warning, click "More info" -> "Run anyway".

## What's New

- 你的消息会在对话第一条、以及距上一条超过一小时的地方显示发送时间（如「昨天 21:14」）；Supervisor 发来的消息始终显示。
- 回答下方的操作栏（复制、保存、token 与上下文占用）只在鼠标悬停在该回答上时显示。
- 侧栏顶部的快捷入口压成一行：「新对话」保留文字，搜索、定时、项目改为图标，名称与快捷键在悬停提示里；新建项目的「＋」移到项目视图的分组标题右侧。
- 英文界面里，新建对话的动作统一改叫「New chat」。
