# 09: 空状态示例（首次教学）

Status: done
PRD: ../PRD.md（决策 10）

## 背景

JC 提出（2026-07-24）：首次打开 dialog 需要案例/建议给用户方向。
第一版提案（git 巡检、依赖检查）被 JC 纠正：Galley 定位不是
Coding Agent，示例不得预设用户写代码。

## 实现

空状态下三个可点击示例行，覆盖 每天/每周/每月 × 三类桌面 agent
能力，点击**预填创建表单**（绝不直接创建），有任务后完全消失：

1. 每天 09:00 · 晨间简报（信息获取；prompt 带「你关注的主题」占位）
2. 每周五 17:00 · 下载文件夹整理（本地整理；只建议删除、不执行删除）
3. 每月 1 日 09:30 · 月度归档（定期维护；只移动 + 清单）

示例与任务行共用 `repeatSummary` helper；文案 zh/en 皆备。

## 约束（设计时定死）

- 仅空状态显示，零常驻 chrome。
- 数量 ≤3。
- 点击 = 预填，用户确认才落库。
- 示例必须开箱能跑、不预设职业、无人值守示例不教授权破坏性操作。

## 待验证

晨间简报依赖联网/浏览器能力，dogfood 时确认当前引擎配置下首跑
可成；不稳则降级或替换为「阅读摘要」备选。
